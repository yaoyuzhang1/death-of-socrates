# 隐藏章节人物配音

本目录配音覆盖 `content/bonus/death.json` 的全部42段场景正文、36组选项中的41段人物回应，以及36段选项说明，共119段。

每段录音使用原有文本，不读人物标签，也不添加新台词。选项回应与说明仅在玩家确认对应选择之后播放。正文可以按段播放；人物回应按段落次序连续播放，最后播放说明。

声线均为微软在线语音服务的标准普通话（`zh-CN`）：

| 人物 | 声线 | 语速 |
| --- | --- | --- |
| 苏格拉底，含拟法律陈词 | zh-CN-YunxiNeural | -5% |
| 旁白、选项说明 | zh-CN-XiaoxiaoNeural | -3% |
| 克里同 | zh-CN-YunyangNeural | -7% |
| 美勒托、西米亚斯、克贝、斐多等其他男性 | zh-CN-YunyangNeural | -3% |

正文文件位于 `intro/`，段落回应位于 `responses/`，选项说明位于 `notes/`。段落编号从0开始。`manifest.json` 保存全部准确文字、声线、文件名、文字与音频SHA-256、字节数及MPEG时长。

生成器为 `scripts/generate-bonus-audio.py`，重跑时只生成缺失或文字、声线、校验值变化的录音。`--verify` 只执行本地核对，不访问网络。

所有119段均已通过MPEG完整性检查，以及Chrome真实解码与非静音波形检查；逐段数据在 `decode-qa.json`。这些检查不等于人工逐字听校。
