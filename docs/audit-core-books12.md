# 第一、二卷核心提问审核

审核日期：2026-09-09。范围：`content/questions/book1.json` 的 18 题、`book2.json` 的 9 题。

底本为郭斌和、张竹明译《理想国》，商务印书馆1986年版。通读了电子底本印刷页2—43、56—81的前后讨论，并逐题目视核对原问所在扫描页：3、5、6、8、10、12、14、17、20、23、29、32、33、38、40、41、57、59、61、65、67、71、74、76、77、80。跨页问句同时核对两页。另核对19、78页的可疑文字。

这里的“较好”只比较一个问题能否把本段正在进行的辨析推进一步，不表示原著中的每一句问话都比其他可能问法更好。备选问题可以有价值；选错反馈应说明它检验了什么、还留下什么。是非问也可以检验条件或暴露矛盾，不能仅凭问句形式把它说成已经肯定了答案。

本轮保留全部原问、题目编号、答案编号、章节定位、印刷页、PDF页、固定提示语及空白提示。修改了40个备选问句、81条逐项反馈、27条说明。没有改动原著正文或分页。

## 核对中发现的正文问题

印刷第19页（PDF第30页）的扫描图明确有独立一段：“色：难道不是谁强谁统治吗？每一种统治者都制定对自己有利的法律，平民政府制定民主法律……” 审核时电子底本把开头截去，并错误并入前一条“苏：是的。利的法律……”。这影响强者、立法与利益的前提，已交主任务依据扫描补齐原文与说话者边界；本次两份题库没有自行改正文。

印刷第78页的“神和人都尽善尽美”在扫描上也如此。即便语义令人疑惑，它不是本次可自行订正的OCR误字，因此保留并在解说中避免把它扩展为无条件的普遍命题。
