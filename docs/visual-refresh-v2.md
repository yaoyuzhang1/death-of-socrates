# 第二版首页与章节视觉设计

2026-09-27，参考[《迷雾中的探险》](https://yaoyuzhang1.github.io/socrates-question/)实际页面中的简短开场、彩色叙事漫画及独立入口卡片，调整《理想国》的阅读入口与章节分隔。

首页只保留一句开场、继续阅读和选章入口。默认按“正义、城邦、认识、政制、命运”五组浏览，每次呈现2—5章。分组只是目录组织，20章始终可独立进入；按卷、按主题、全部章节和短阅读路线仍可展开使用。人物、术语、玩法、详细记录与全书统计移到折叠说明中。

每章有不同的封面卡，突出章节编号、章名、所属卷和一句讨论焦点。阅读记录与篇幅另行展开。章首和章末使用同一章的封面及醒目编号，分别标明编辑导引和编辑回顾；正文首屏不再重复另一张场景图。其余正文页保留原有场景配图。切章后的键盘焦点进入正文，目录锚点为固定页头留出空间。

新生成四幅彩色漫画封面，用于太阳与善、民主城邦、摹仿和命运选择。人物采用自然表情、手势和衣着，增加海蓝、陶土红、苔绿与暖色石材。20章封面使用20个不同图像文件；其中16幅来自既有插画，四幅为本轮新图。编辑想象与谈话中例证都保持标识，尤其命运封面明确为“编辑封面 · 选择的意象”。[封面清单](../content/art/chapter-covers-v2.json)和[生成提示词、路径与散列](chapter-cover-prompts-v2.md)可供核查。

正文、原问、理解检查、解释录音及进度格式均未修改。主题章保持原来的划分与顺序，不为视觉分组改变论证结构。原8章的隐藏奖励和全20章的全书总结继续分别保留。

## 实际验证

- 95项自动化测试、类型检查与生产构建通过。
- 实际浏览器逐组检查五组、20个入口和20幅封面，逐章打开核对章名、章首与源文正文；20章均可进入。
- 桌面及390像素手机视口无横向溢出。首页默认仅显示当前组，人物、玩法、统计和细节默认折叠；已检查彩色封面及手机章首、章末。
- 独立本地测试存档验证错选反馈、正确后继续、声音解释控件、切章、书签与刷新后的原位置保留。
- 实际导入旧8章备份：8/20已读完、47/95首次作答和隐藏资格保留；新增12章没有被算作完成。实际导入全20章备份并打开末章：95次追问、全书总结、章末回顾及隐藏入口保留。

本轮没有重新走完全部619页；完整逐页通关属于前一全书版本的验证。此次代码范围集中于展示，最终发布仍需核对对应提交的部署工作流和线上实际页面。
