# 普通话配音制作

游戏的预录语音使用微软在线语音服务，通过 `edge-tts` 制作。人物主对话、选定立场之后的回应，以及由此前选择触发的回声均逐句导出；按钮、未选立场和教学提示不进入这份配音清单。

## 当前发布素材

2026年9月7日制作并核验：291句去重台词、17个角色、17,091个文本字符，对应291个MP3。全分支音频合计3,740.544秒（约62分21秒），文件合计22,443,264字节（约22.44 MB）。最终清单与当前剧情逐字对应，没有缺失、过时条目或无引用音频。

所有声线均经当次实时清单确认属于 `zh-CN`，所有逐词文本匹配，所有MP3完成了非静音PCM解码与SHA-256校验。制作过程中的短暂网络失败经重试恢复，最终无未解决的合成异常。以下试听入口供人工复核使用，尚未完成真人听审：

## 可重复制作

1. 在安装了项目依赖的目录运行 `pnpm voice:export`，生成忽略版本管理的 `.local/voice-cues.json`。
2. 在 Python 环境安装 `edge-tts==7.2.8`，解码环境需要 `numpy` 以及 `av` 或 `soundfile`。如合成与解码位于不同环境，可通过 `--decode-python` 指定解码解释器。
3. 运行 `python scripts/generate-voice.py --concurrency 3`。此步骤会将导出的游戏台词发送给微软在线语音服务。
4. 合成脚本在全部目标完成后写出 `public/voice-manifest.json`；音频位于 `public/voice/`。同一角色与文本只生成一次，脚本支持按请求指纹及音频 SHA-256 校验后断点续跑。

## 声线与语言

`scripts/voice-cast.json` 保存角色声线、语速、音高及表演参考。主要人物沿用苏格拉底 Yunxi、克法洛斯 Yunyang、玻勒马霍斯 Yunjian、旁白 Xiaoxiao。新增角色使用标准普通话声线，并结合语速、音高作有限区分。

每次制作均读取实时声线清单，要求声线的 `Locale` 严格等于 `zh-CN`；不接受粤语或地区方言。角色说明是人工制作与听审的参考，语音接口实际接受的是声线、语速、音高，不会自动执行复杂表演指令。共享基础声线的角色也不能据此视作具有完全独立的真人声纹。

## 校验与边界

- 服务返回的逐词文本，经 Unicode 规范化并忽略标点后，必须与原台词完全匹配。
- 每个 MP3 均实际完整解码为 PCM，检查非空有效音频、时长和最后一个词的位置。脚本支持 PyAV；没有 PyAV 时使用 SoundFile/libsndfile，本次制作沿用已经安装的 SoundFile 环境。
- 文件 SHA-256 与原始“角色＋台词”的 SHA-256 写入清单。
- 边界文本匹配证明服务返回了对应文本，不能独立证明发音、情感或每一个实际声学片段都正确。
- 本次制作不将机器校验称为人工听审，也不将声线地区标识称为逐句口音听辨。尚需真人重点试听情绪转折、人名、引语以及角色共用基础声线的段落。

完整分支音频的总时长包含互斥回应与条件回声，不能视为一次通关的播放时长。中间边界记录、错误记录和本机制作日志均留在不公开的 `.local/` 中；公开清单不包含本机路径或凭据。
