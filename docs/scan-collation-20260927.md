# 全书扫描文字复核

本轮按用户要求重新核对游戏主篇与郭斌和、张竹明译《理想国》，商务印书馆1986年8月第一版。底本仍为指定的459页PDF，其SHA-256为`4d8d8c8a9c29ca24edaba68ac418aa68e9b8739e2fe47004c34b0cbea33a739b`。正文范围为全十卷、印刷页1—426，对应PDF第12—437页。

## 原典层与编辑层

主篇人物发言、叙述、诗句与苏格拉底原问都以这份扫描的字面为准。不因措辞不常见、译词较旧或推论可争议而改写原译。人物侧栏、章节划分、导引、备选问法、理解题和解析属于游戏编辑材料，不能把它们归为译者原文。

隐藏章另据《申辩篇》《克里同篇》《斐多篇》的Jowett历史英译作中文节译，已分别标识来源；它不是《理想国》的一部分，也不是郭、张译文。本轮不以《理想国》文本替换另三篇作品的谈话。

## 核对方法

对426页逐页比较已有RapidOCR与Windows OCR结果，筛出与当前正文不同的中文、漏字和可疑标点，再看本地原页图确认。第二个识别引擎的结果不是裁定依据；两个引擎相同也不能自动作为修订。正文与译者注分别定位，脚注不并入人物对白。

每项确认的修订记录印刷页、修改前后文字及核图说明。修改仅在指定页的唯一段落或注释处应用；保留真实段落、章节及题目稳定标识。第226页竖写批注“理想”和第386页末尾“王才”均不是原典正文；删除时保留旧编号`p-2426`、`p-4084`为空缺，后续原典段落不重编号。修订程序也接入原OCR归整与全书追加流程，避免重新整理时覆盖已核实的修订。

构建随后比较全书电子稿与游戏中的全部原典段落，保证电子稿的字符完整出现一次、顺序相同。这个比较可发现游戏收录遗漏或重复；它本身不能证明电子稿与扫描逐字无误。
