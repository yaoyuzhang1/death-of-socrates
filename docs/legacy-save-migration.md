# 旧版分页存档兼容

## 第四版页码使用冻结位置

2026-09-09 的原文复核补回了答语、叙述并修正字误，还把一处判断题移到原段中带有限定条件的下一问。旧版按同一算法重新分页，已经不能得到当时发布的页码边界。因此，不能把新的分页结果当作旧存档的页码表，也不能仅修改测试中的页数。

`src/reader/legacy-v4-pages.ts` 从修订前提交 `ce1cb2e165e2e6c2536cc6f92ba2cf51be34d8ed` 的 `reader-public/text/republic.json` 一次生成，固定了53个阅读单元、743个文本页和47道题页。文件记录原语料的 SHA-256；测试还固定整张位置表的 SHA-256。后续修改原文时不得重新生成这张表。

表中只有各页首字符的原段编号、UTF-16 字偏移、段落次序及内容指纹，没有复制整份旧原文。长度与 FNV-1a 指纹用于发现文本变动，不承担安全认证用途。

迁移规则如下：

- 原段文字未变，按冻结字偏移定位到当前包含该字符的页面。
- 原段改过，回到当前段首；紧接在其前的新答语或叙述也纳入回读，避免字数变化导致跳过恢复的文字。
- 原段被删除或移到题门另一侧，在原侧回到较早的存续段；没有这样的段时，从该侧开头恢复。
- 旧题页直接对应当前题页。旧题后页仍须先通过旧存档的已答对校验，文本定位不得穿过题门。
- 旧像素滚动位置清零；首答、重答、书签和章节进度继续由既有存档校验保留。第四版以外的现行页码保存方式不由这次迁移改写。

`makeVersion4ReadingPages` 对已发布单元返回冻结的位置描述，只用于存档边界校验与迁移，不供正文显示。未列入表中的测试或自定义语料仍使用旧算法；新游戏阅读始终使用当前完整正文及原有的新分页算法。

## 回归验证

分页与引擎的44项测试通过，另通过 TypeScript 检查。覆盖全部790个旧位置、片段偏移与原段字符对应、补回的第19页答语和第57页叙述、等长改字、插入或截短长段、删除原锚点，以及“仅就正义的概念”题目后移后的真实第四版存档导入。未答存档无法借旧题后页打开新原问；旧已答存档保留首答并恢复到当前题后阅读。

修订前后53个单元的旧分批阅读数量另行比对一致，因此本轮未改变 `reading.positions` 的批次数值含义。
