# 底本与校订说明

正文采用柏拉图《理想国》，郭斌和、张竹明译，商务印书馆 1986 年 8 月第一版、北京第一次印刷，统一书号 2017·366。依据指定的 459 页扫描文件整理；标题页及版权页已核对。

## 收录范围

第一至十卷完整正文，即印刷页1—426、扫描文件第12—437页。各卷印刷页起点为1、44、82、132、177、228、272、312、352、387。译者引言和全书索引不列入游戏对白；译者注与正文分开，并可在相应原书扫描中核对。

二十个主题章依照对话转题处划分，前八章的边界与稳定定位保持。新增十二章涵盖护卫者共同生活、哲学家统治、哲学家与现实城邦、善的比喻、洞穴、辩证教育、政制退变、民主与僭主、欲望与快乐、摹仿及灵魂报偿。玩家可任选一章开始，各章内保持原书次序；导引与回顾标为编辑内容，不把编辑文字当作原典发言。

八章全部完成后开放的《苏格拉底之死》是另外的12幕互动节选，取材于《申辩篇》《克里同篇》《斐多篇》。人物对白主要从 Benjamin Jowett 历史英译独立节译为中文，节述、编辑连接和说明分别标识；这不是郭斌和、张竹明译文，不计入上述正文覆盖数字。149条来源映射含结尾文字，独立底本与作品位置见[隐藏章节审查](audit-bonus-source.md)和[来源说明](death-sources.md)。

## 电子整理

扫描文件在本地通过 Windows OCR 定位，再用 RapidOCR / PP-OCRv4 中文模型识别。文字、坐标和识别置信度供版面整理及校正使用；没有向在线识别服务上传源文件。页眉、边码与译者注和正文分开；印刷页号可追溯到原版扫描。

正文保留人物发言、短应答、诗句以及跨页连续论证。保留本译本的姓名、旧式用字和实际措辞，如“格劳孔”“阿得曼托斯”“护卫者”，不统一改写为上一版的术语。对“心灵”“灵魂”等词按本页字面保留，不机械全局替换。

初次整理中经核实的录入修正保存在 `content/source/guo-1986-corrections.json`；本地归整程序为 `scripts/normalize-guo-ocr.py`。该阶段共应用379处修正（同一规则可命中多处），另恢复11页的191个角色发言段落起点，不进行按语义自动改写。

2026-09-09本轮审查另记录22项扫描核实的修正，见 [`guo-1986-review-corrections.json`](../content/source/guo-1986-review-corrections.json)，涉及印刷第16、18、19、24、25、29、47、50、55、57、132页。第19页恢复了被截去的色拉叙马霍斯发言，并将前面的“苏：是的。”独立；第57页按原书把叙述与随后苏格拉底的长段发言分开。其它项目包括漏括号、标点及可确定的识别误字。正文字符由83,852变为83,876，原1,862个段落ID保留，新增两个固定ID，不以连续重编号破坏旧定位。

47题均连同前后讨论核对原文。46题保留原有原问，`book4-same-form` 一题将考点后移至同段的“那么，如果仅就正义的概念而论，一个正义的个人和一个正义的国家也毫无区别吗？”。原来的泛问和“相同”应答仍是正文；这项调整使用原书已有句子，没有补写苏格拉底的话。题目与正确选项ID保留。

备选问句与题后反馈属于编辑内容。本轮将同一问题中值得追究却不够充分的问法与原问比较，说明其对象、条件或推论环节，不以原问的作者身份保证优越，也不把一般疑问句说成已经断言结论。逐题依据见[第一、二卷审查](audit-core-books12.md)、[第三、四卷审查](audit-core-books34.md)及[本轮汇总](source-question-review.md)。

书页对照保留印刷页1—426的扫描图。译者注可在对照页及扫描中查阅；正文中的圈注应按同页原注理解。此次核对覆盖题目所在页、必要前后文及发现的可疑位置，未完成426页逐字学术校勘。字符覆盖校验只检查校正后电子正文的收录、次序及重复，不证明 OCR 无误或解释已获学术审定。发现问题时，应先比对对应原版页图。

## 全书扩展（2026-09-27）

原第一至四卷176个页对象全部保留。后六卷新增250页，经本地RapidOCR与Windows OCR两个结果比对漏行，并对卷首末、主题边界、题目原句及疑难页目视核对。恢复第247及425页识别漏行，依据扫描将正文、脚注和边码分开；确定的字、标点与角色起点修复记录于[全书校正表](../content/source/guo-1986-fullbook-corrections.json)。这不是将英文转译稿拼接为后半部。

新增48处核心题逐条核对原问与实际论证对象。51处理解检查另核对可见分页的文字依据；解释区分作者的推论与已成立的普遍事实，尤其保留城邦与个人类比、快乐判断、灵魂不死及神话的论证边界。题目和学理审查见[全书审查表](fullbook-logic-audit.md)。

字符覆盖与段落顺序检查核验完整电子稿只被收录一次。OCR双结果比较和部分页目视检查仍不等于全426页逐字校勘；读者可直接打开原版扫描核查。

## 原书字面与识别错误

明显的 OCR 误识依图修正，保留原译词语。第 174 页“合自然”相对位置两次印作“仅自然”；电子正文保留这一字面，不将它冒充识别错误直接改成“反自然”。此项记录是文本校核说明，不是扩写原文论证。
