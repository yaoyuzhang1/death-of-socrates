# 底本与校订说明

正文采用柏拉图《理想国》，郭斌和、张竹明译，商务印书馆 1986 年 8 月第一版、北京第一次印刷，统一书号 2017·366。依据指定的 459 页扫描文件整理；标题页及版权页已核对。

## 收录范围

第一至四卷完整正文，即印刷页 1—176、扫描文件第 12—187 页。各卷起点为印刷页 1、44、82、132，第五卷从 177 页开始，不在本次收录范围内。译者引言、全书索引和第五至十卷不列入游戏正文。

八个主题章依照对话转题处划分：日常义务；统治与利益；正义与生活；正义本身；城邦的起点；教育；护卫者与全城；城邦与人的正义。分章不改动正文次序，原先的章前阐释、章末结论和题前提示已移除。

## 电子整理

扫描文件在本地通过 Windows OCR 定位，再用 RapidOCR / PP-OCRv4 中文模型识别。文字、坐标和识别置信度供版面整理及校正使用；没有向在线识别服务上传源文件。页眉、边码与译者注和正文分开；印刷页号可追溯到原版扫描。

正文保留人物发言、短应答、诗句以及跨页连续论证。保留本译本的姓名、旧式用字和实际措辞，如“格劳孔”“阿得曼托斯”“护卫者”，不统一改写为上一版的术语。对“心灵”“灵魂”等词按本页字面保留，不机械全局替换。

经核实的录入修正保存在 `content/source/guo-1986-corrections.json`；本地归整程序为 `scripts/normalize-guo-ocr.py`。本次共应用367处修正（同一规则可命中多处），不进行按语义自动改写。

原问与正确选项逐题对照扫描核对。原问对应选项采用原句，另两项只是对同一对象、条件或关系的小幅变化。题后只说明本段问答关系，不新增反例、人物心理、现代评价或远处结论。

书页对照保留印刷页 1—176 的扫描图。译者注可在对照页及扫描中查阅；正文中的圈注应按同页原注理解。字符覆盖校验检查电子正文的收录、次序及重复，不证明 OCR 无误或解释已获学术审定。发现问题时，应先比对对应原版页图。

## 原书字面与识别错误

明显的 OCR 误识依图修正，保留原译词语。第 174 页“合自然”相对位置两次印作“仅自然”；电子正文保留这一字面，不将它冒充识别错误直接改成“反自然”。此项记录是文本校核说明，不是扩写原文论证。
