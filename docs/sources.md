# 来源与解释边界

## 三个层次

**文本依据**：游戏为关键谈话标明柏拉图篇目和段落范围。引用编号便于回到原典核对，不意味着当前界面的中文句子是逐字译文。

**中文重述**：为对话节奏重新组织论证、压缩较长段落，并使用可读的现代中文。应按“本游戏据某篇重述”理解，不应加上引号当作柏拉图的直接引文。

**游戏演绎**：玩家进入谈话、人物对玩家的回应、活动中的数值和案例、跨篇的选择回响与结局，都属于叙事与交互设计。场景的 `frame` 字段说明这一层边界，`source` 字段说明相应的文本依据。

柏拉图的对话作品本身也有文学组织。将不同篇目的情境串联为一条玩家经历，不等于确认了一份逐日发生的历史记录。游戏保留苏格拉底之死这一历史背景，不通过“正确选择”许诺改变已经发生的历史。

## 解释上的约束

- 一个反例可以推翻全称断言；它不能单独确定造成差异的原因。
- 克法洛斯重视某项义务，不能自动推出游戏已经证明所有玩家都负有同样的义务。
- 提出“存在风险”仍需说明风险的证据、限制的边界和复核的办法。
- 不同意苏格拉底并不自动构成论证失败；同意他也不自动证明玩家已经回应了反对意见。
- 人物之间的信任与一条主张是否有充分理由，是相关但不同的问题。
- 自由文字没有被机器理解或评分。结局回顾的是所选立场和未决问题，不是心理诊断或思想能力测量。

绘画也是后世的解释。大卫 1787 年的《苏格拉底之死》距事件发生已有两千多年；庭院场景图是 AI 艺术想象，两者都不能作为古代空间与人物外貌的直接证据。
