50道新增理解判断的150段选项解释已获授权，通过微软在线语音服务生成，采用晓晓标准普通话声线，语速为-3%。选对朗读该题的正确解释，选错朗读对应选项的反馈；均保留现有准确文字，不添加台词。声音清单为150/150，包含逐段文字与文件校验信息。

本批录音逐段通过文字、声线、文件SHA-256和MPEG检查，以及Chrome真实解码和非静音检查。浏览器另验证主篇与隐藏章节的正确、错误解释按确认项播放，支持停止、重听、重答、静音，打开插图、书页、菜单及翻页时中止；隐藏章节的旧人物回应不会与判断解释串播。首次选择及通关记录继续保留。

生成器给每次请求设置60秒总超时，并逐项验证可复用的录音，避免服务保持连接但不返回音频时无限等待。首次批量中两段未返回音频，保留148段成功录音后单独补齐，没有重新生成整批。
