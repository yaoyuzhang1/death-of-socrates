# 阅读与练习

逐页阅读《理想国》第一至四卷，在关键处选择“哪句话更像一个好问题”。八个主题章保留原书卷次及讨论次序。

## 翻一页原文

正文分为743个短页，每页最多260字、三段；另有47个追问页。长发言在标点附近分为续页，人物原话、标点和对话次序完整保留。翻页替换当前内容，不再向下堆叠全文。页码与阅读位置自动保存。

对话用衬线字体，苏格拉底的发言配浅绿色底色，其他人物用温暖的灰褐标记；叙述字体稍小、底色更轻。姓名、颜色和字号共同区分发言，原文中的人物简称仍保留。每页的场景漫画可点击放大，关闭后继续阅读。

页面下方可以前后翻页。目录和书签用于回看已读小节；回看后可用“回到最新进度”继续主线。

## 选一个问题，听解释

在追问页比较三个问法，选择后点击“确认选择”。原问选项取自译本，另两项围绕同一对象、条件或关系作小幅变化。题前没有解题提示，选择尚未确认时也不会播放解释。

选错会出现明确的错误标记、短促动画与柔和提示音，并朗读所选项的解释。点击“再试一次”回到选项；必须选对才能进入后文，刷新和离开再回来也不会跳过这一要求。

选对后出现成功标记和动画，朗读“为什么这一问更好”。随后点击“继续读原文”，按原有顺序阅读苏格拉底的原问、续句和对方回应。需要时展开“对照另外两个问法”查看已有说明。这些解释属于编辑文字，没有改动原典。

长选项的确认区保持可见。焦点在选项内时，1—3选择、Enter确认；数字键选中后，会把对应选项带到可读位置。动画尊重系统的“减少动态效果”设置。

## 声音设置

141条录音采用标准普通话晓晓声线：47条正确解释、94条错误选项反馈。只朗读已经确认的那一项解释，不提前读出正确答案。声音和配音都可在“阅读设置”分别开关；“重听解释”可以再次播放，正在播放时可直接停止。

翻页、退出、切换到后台或关闭声音会停止当前录音。若浏览器暂时阻止播放，界面提示点击重听。原文不自动配音，阅读期间保持安静。

## 再练一轮

工具栏和首页的“重练”每轮最多五问，先安排首次未选中且尚未重练答对的题。每轮重新排列选项，题前原文可分页回看。选错时仍需重新作答；答对后分页对照原问与回应，再进入下一问。

本轮结果显示“一次选对”的题数。需要重答的题可以再练一轮。首次答案与练习记录分开保存，重练不会覆盖主线首次记录或移动主线阅读位置。

## 进度与原书核对

页码、首次答案、通过状态、书签和字号自动保存在当前浏览器。v2/v3旧存档自动迁移，旧版已经读过的内容继续开放。“阅读设置”提供导出、导入；换浏览器前可导出备份。

正文支持16—32px字号、纸色与夜间背景。正文旁的“书页”链接在当前页打开原版扫描和译者注；可以翻页、放大，关闭或按Esc回到阅读位置。书页包含该页后文，连续全文入口仍保留。

应用无需账号，没有云端评分或作答收集接口。游戏运行时播放随站点提供的解释录音，不再向语音服务发送台词。
