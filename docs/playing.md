# 阅读与练习

《理想国 · 苏格拉底的下一问》是一部纯文字互动阅读作品。按原文顺序阅读第一至四卷，在八个主题章中完成 52 次追问练习。主题章是帮助阅读的编辑划分，不是柏拉图原书的卷数，也没有补写第一至四卷之外的结局。

## 在关键处选择一个问题

先读已经展开的对话。出现“停一停，想一问”时，比较三个问法，选择更能推进当前思考的一项，再按“确认选择”。要比较的是它能否澄清对象、检查理由或揭示问题，不是猜哪一个选项的措辞更像古代作者。

你可以先点“给我一点提示”，也可以点“直接看原文”。无论选对、选错或直接揭示，页面都会展示实际问句的中文转译、为什么这一问更有价值，以及另外两问各自的局限。然后继续读同一份正文；选择不会生成支线，也不会改写人物的后续话语。

“为什么更好”是当前教学目标下的比较，不是说其他问题永远没有价值。正文中的回答也不因它出自苏格拉底就自动得到证明。类比是否恰当、前提是否可靠、适用范围是否太大，仍然可以追问。

## 进度、复习和章末

按“继续阅读”依次开放后面的阅读位置。有题目的位置必须先作答或直接揭示。完成一章后，页面呈现章末回顾、首次答对数、直接揭示数和使用提示数，也可回到本章的追问处复习。

目录可以进入已开放的小节。正文上方的书签按钮可以收藏或移除当前阅读位置；书签出现在目录中。“上一节”和“重新练习这一问”供回看与复习使用。

首次答案保留，不会因为复习时重新选择而覆盖。回看也不会截断后面的阅读进度。显示的统计只描述本次首次作答记录，不是哲学能力测量，也不是对读者立场的评分。选项的排列在同一份进度中保持稳定，字母位置本身不表示优先级。

## 保存与备份

游戏自动把阅读位置、首次答案、提示记录、书签和阅读设置保存到当前浏览器的本地存储。刷新或再次打开同一地址时，会尝试恢复。它不提供账号和云端同步，也不迁移旧叙事游戏的存档。

“阅读设置”中的“导出进度”会下载 JSON 文件；在另一浏览器中使用“导入进度”即可读取兼容的文件。导入在设备上处理，不向开发者上传。损坏、进度不连贯或正文版本不匹配的文件会被拒绝；不要手工修改文件来跳过尚未开放的内容。

清理站点数据、切换浏览器或站点地址、退出临时浏览模式，都可能影响保存。浏览器拒绝本地存储时，页面会提示导出备份。“重新开始阅读”需要再次确认，会清除当前浏览器的本次阅读与作答记录；如需保留，请先导出。

## 阅读设置与键盘

阅读设置提供正文字号调整，以及纸色和夜间背景。浏览器自身的页面缩放也可使用。

使用 `Tab` 与 `Shift + Tab` 移动焦点，用 `Enter` 或空格操作按钮。题目采用原生单选控件，可用方向键切换同组选择。对话框可用关闭按钮或 `Esc` 关闭；页面有“跳到正文”入口。

作品没有配音或音效，不需要麦克风、语音权限或音频设备。这里列出的是操作方式；不同设备、辅助技术与高倍率缩放的实际兼容性，需要按[验证说明](validation.md)检查，不能仅凭这些控件推定已完成无障碍认证。

## 来源与隐私

通过“底本说明”查看文本来源。正文为 AI 辅助的 Shorey 英译转译；题目及其解释是编辑内容。第一至四卷包含古代关于性别、奴隶、审查、医疗和统治的争议主张；保留这些段落是为了完整阅读论证，不表示项目赞同它们，或把它们作为现实行动建议。

应用不收集作答，不包含广告追踪、应用分析或远程 AI 评分。正常加载网页与正文仍会向 GitHub Pages 请求资源，打开底本链接会访问对应外部网站。
