# 阅读与练习

按原文顺序阅读《理想国》第一至四卷。八个主题章是阅读分段，保留原书卷次及对话次序。

## 选择一个问题

出现“停一停，想一问”时，比较三个问法，选择后确认。问题统一为“下面哪句话更像一个好问题？”，题前不提供思路提示。原问选项采用译本中的实际问句，另两项围绕相同对象、条件或关系作小幅变化。

作答后显示实际原句、“为什么这一问更好”，以及另两项在本段讨论中的局限。说明只解释本问承接的前提和论证步骤，与原文分开。选对、选错和“直接看原文”都能继续阅读相同正文。

## 回看与进度

用目录回到已开放的小节，用书签收藏阅读位置。首次答案保留；重新练习不会覆盖首次记录或删除后续进度。章末列出本章追问、首次答对数和直接揭示数。

阅读位置、答案、书签和设置自动保存在当前浏览器。“阅读设置”提供进度导出和导入；更换浏览器前可导出备份。正文版本改变时，旧进度不会错配到新内容，会明确提示建立新的阅读进度。

## 字号与原版书页

字号可调为 16—32px，背景可选纸色或夜间。正文旁的“书页”链接打开原版扫描与该页连续文字，保留译者注，供核对。书页包含本页后文。

用 Tab 移动焦点，Enter 或空格操作按钮，方向键切换单选项；对话框可用 Esc 关闭。

作品没有配音或音效。应用没有账号、云端评分和作答收集接口；网页和静态正文由 GitHub Pages 提供。
