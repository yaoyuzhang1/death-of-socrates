# 玩法与内容说明

## 你在游戏中做什么

你的任务是提出一项能说明理由的判断，并观察它面对不同人物和情境时如何变化。选择并不等于证明；人物的赞同也不等于结论成立。

故事依次经过“庭院之约”“正义的边界”“城邦的法庭”“牢门之前”“最后一天”，共二十处场景。这个顺序组织的是一次后世读者的回望，不是把四部对话当成连续发生的历史记录。

阅读场景后，先看材料，再选回应。需要操作的场景会提供证言、有限资源或具体案例。没有要求你找出一条“官方最优人格路线”。不同立场会带来不同的解释责任，已作出的选择会影响后续人物的接话。

可选札记适合记录：“我依据什么这样判断？”“有什么新证据会让我改变看法？”“这个理由在另一种情境里还成立吗？”札记不会被自动分析，不参与隐藏的 AI 评分。

## 回溯与存档

游戏自动保存当前进度到浏览器的本地存储。离开页面后，使用同一浏览器和地址重新进入即可继续。

导出存档会下载一份 JSON 文件。它包含选择和你写下的札记；分享文件前，请自行检查文字是否适合公开。导入只在当前设备读取文件，不上传给开发者。无效或不兼容的存档应被拒绝，原进度不应因此被覆盖。

回溯用于重新考虑已经作出的判断。回到较早位置后，后面的选择会被截去，因为它们可能建立在已经改变的承诺上。想保留两条路线时，先导出当前存档。

浏览器的本地存储不是永久备份。删除站点数据、更换域名或浏览器、使用临时浏览模式，都会影响存档的持续性。

## 键盘与声音

使用 `Tab` 和 `Shift + Tab` 移动焦点，按钮可用 `Enter` 或空格触发。对话和操作均有文字标签；不需要依靠声音完成判断。

预录音轨使用普通话。首次播放可能需要点击声音控制按钮，以满足浏览器的自动播放规则。关闭声音不影响剧情。播放结束不会自动选择回应或推进剧情。

音轨是现代合成演出，不代表人物的历史声线。没有音轨或播放失败时，请继续阅读字幕；游戏不会自动改用设备上的其他方言声线。当前版本的实际声音覆盖以游戏界面和发布说明为准。

## 阅读范围与隐私

游戏涉及审判、监禁、死亡和哲学分歧，以文字叙事和绘画呈现。结局关注你留下的理由与问题，不把人物的死亡当作玩家获得的奖励。

本项目没有应用账号、广告追踪、应用分析或收集玩家札记的后端。运行时不请求语音生成服务；预录文件与网页资源一起加载。托管平台处理网页访问和资源请求，打开原典等外部链接也会访问对应网站。
