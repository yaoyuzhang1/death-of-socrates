# 阅读与练习

按原文顺序阅读《理想国》第一至四卷。八个主题章是阅读分段，保留原书卷次及对话次序。

## 一次读一段

默认“分段阅读”：长篇前文按原有完整段落分批显示，点“读下一段”继续，并把视口和键盘焦点移到新段；全部前文展开后进入提问。作答后先读原回应，较长的后文用“继续读原文”逐步展开。段落不截句、不改写，展开位置自动保存；阅读设置可随时改为“连续全文”。切回分段时保留当前已显示正文，从下一节采用新的节奏。

章内数字标记显示哪些题已遇到、哪些题首次选中了原问，不提示下一题的内容。章末仍能进入下一章，也能选择“重练本章”。

## 选择一个问题

出现“停一停，想一问”时，比较三个问法，选择后确认。问题统一为“下面哪句话更像一个好问题？”，题前不提供思路提示。原问选项采用译本中的实际问句，另两项围绕相同对象、条件或关系作小幅变化。

确认区在长题目内保持可见，显示当前选择的字母；确认前可以继续比较或改选。选项获得焦点后，1—3切换选择，Enter确认；其他阅读位置的按键不会提交答案。点击“重新练习这一问”后，视口和焦点回到选项。

作答后先显示实际原问、同次发言的续句和对方的完整回应，再显示“为什么这一问更好”，以及另两项在本段讨论中的局限。说明只解释本问承接的前提和论证步骤，与原文分开。选对、选错和“直接看原文”都能继续阅读相同正文。

## 回看与进度

工具栏“重练”或首页“开始一轮重练”会从已作答题中选出最多五题。先安排尚未重练答对的首次错选、直接揭示题，同组优先安排练得少、较久未练的题。每一轮重新排列选项；需要时展开“回看这段原文”。回答后对照原问、完整原回应与说明，再进入下一问。

一轮结束显示本轮结果，可以再练本轮未选中的题，或者返回之前的阅读位置。首次记录和重练记录分开保存；重练答对一次后，该题不再计入首页“待重练”，这个计数不代表对哲学问题的最终掌握。

用目录回到已开放的小节，用书签收藏阅读位置。首次答案保留；重新练习不会覆盖首次记录或删除后续进度。章末列出本章追问、首次答对数和直接揭示数。

回看旧节时，阅读页、首页及目录提供“回到最新进度”。滚动后立刻回首页也会保存刚刚的位置。复习结束按钮按实际来源显示“返回首页”“返回本章小结”或“返回阅读”。

阅读位置、答案、书签和设置自动保存在当前浏览器。“阅读设置”提供进度导出和导入；更换浏览器前可导出备份。正文版本改变时，旧进度不会错配到新内容，会明确提示建立新的阅读进度。

## 字号与原版书页

字号可调为 16—32px，背景可选纸色或夜间。正文旁的“书页”链接在当前页面打开原版扫描及译者注，可以翻页、放大；关闭或按Esc回到原来的阅读位置与链接。跨页段落列出涉及的各个书页，保留原段连续阅读。书页包含本页后文；窗口内的“打开连续全文”仍可另开完整对照页。

用 Tab 移动焦点，Enter 或空格操作按钮，方向键切换单选项；对话框可用 Esc 关闭。

作品没有配音或音效。应用没有账号、云端评分和作答收集接口；网页和静态正文由 GitHub Pages 提供。
