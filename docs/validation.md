# 验证方法与质量边界

本文针对《理想国 · 苏格拉底的下一问》的纯文字阅读版本，记录可复现的验收方法与证据边界。旧叙事游戏的二十场浏览器记录及音频检查不适用于本版本。发布证据应来自相应提交的实际输出。

2026-09-08 发布前，19 项阅读引擎与内容测试以及 TypeScript / Vite 生产构建通过。生成结果为 555 个页码小节、八个主题章、34 个小节、58 个阅读单元、52 道题，中文正文合计 88,207 字符（含标点）。

Chrome 生产预览完成了一次从首页到八章结束的真实点击流程，包含 18 次正确选择、17 次错误选择与 17 次直接揭示。每题均检查答前隐藏、答后原问和解释及另两项反馈；另检查提示、复习不覆盖首次记录、刷新、同位置存档导入、损坏文件拒绝、书签、读完后回读早章再进入对应下一章。1440 像素桌面与 390 像素移动视口（含 32px 字号、夜间模式）无横向溢出，未出现音频请求、控制台错误、脚本异常或失败请求。这些证据仅涉及所测环境与操作，不等于已覆盖全部设备或所有无障碍场景。实际公开部署状态以对应 GitHub Actions 记录与线上页面为准。

## 数据与连续性

源数据应包含第一卷 136、第二卷 132、第三卷 156、第四卷 131 个页码小节，共 555 个；题库应分别包含 18、9、12、13 题，共 52 题。按原文顺序组成八个主题章。

复现步骤：

```sh
pnpm install --frozen-lockfile
node scripts/build-reader.mjs
pnpm test
pnpm run build
pnpm run preview
```

检查 `content/source/` 中每卷中英文的 `ref` 顺序完全一致，内容非空，页码不重复。检查题目 ID、选项 ID、正确选项及主题归属有效，题目锚点为相应中文正文的精确连续字符串。尤其注意同一页码中发生主题切换、同页设置多个题目，以及句子跨页码的情况。

对生成的 `reader-public/text/republic.json` 应按实际阅读顺序重组“题目前正文、揭示的原问、题后正文”，与完整中文源文比较，验证题目插入没有丢字、重复或改变次序。对照 `parallel.html` 和 `coverage.json` 检查分节与范围。这些检查证明的是结构对应，不能单凭覆盖率证明每个分句翻译正确。

## 阅读引擎

[reader-engine.test.mts](../tests/reader-engine.test.mts)针对真实引擎，覆盖顺序展开、稳定选项排列、待答位置阻止前进、正确与错误及直接揭示都返回同一正文、首次作答不可覆盖、提示统计、最后位置边界，以及回看不截断进度。

导入测试应拒绝不连贯的完成前缀、未开放位置的答案、遗漏已完成题目、未知问题或选项、错误正文版本、不一致的提示、越界设置、异常时间或位置。有效存档应能往返，并避免保留外部输入对象的可变引用。

测试用的简短语料可以验证规则，但不能代替对整份 555 小节正文的集成检查。运行结果应注明提交号、命令及通过或失败的数量；修改正文版本、题目锚点或构建方式后，应重新检查相关约束。

## 真实浏览器流程

至少使用一份全新浏览器状态，通过真实界面从首页开始，按顺序走完八章；不能只注入一个完成存档来代替全流程。在不同题目上分别选择正确问法、另一问法、使用提示和直接揭示，确认每次都出现原问、主解释与两个局限反馈，随后能继续相同正文。

另外验证：

- 首次提交后刷新，答案与位置恢复；在长段落中刷新，阅读位置能够合理恢复。
- 重新练习可以显示新的反馈，但不改首次答案、提示使用或章末统计；回看不清除已完成的后续内容。
- 目录只开放可访问的位置；书签添加、移除、跳转和刷新恢复有效。
- 导出进度后重新导入，可以恢复；损坏或正文不兼容的文件不覆盖原进度；重新开始须确认。
- 纸色、夜间背景及字号设置保存；桌面 1440 像素、移动 390 像素和 200% 缩放下，正文、题目、章末和对话框没有横向溢出或遮挡操作。
- 键盘能到达主要操作；对话框开启后焦点受到管理，`Esc` 关闭后能继续操作；检查原生单选控件和跳到正文入口。
- 控制台没有未处理异常，正文与静态资源没有失败请求；纯文字版本不发起音频播放或语音生成请求。

浏览器检查应记录浏览器版本、生产预览或公开 URL、视口、实际步骤及截图。模拟移动视口不等于真实手机覆盖，普通键盘检查也不等于屏幕阅读器或完整无障碍认证。

## 尚未由自动检查证明的事项

中文正文和题库由 AI 辅助制作，尚未经人工哲学或古典学专家逐段校订。已知电子录入错误的修正见[底本说明](sources.md)，并不意味着其他内容已经全面校勘。完整保留页码与原文次序，不能保证每一处转译、说话者判断或概念选择都准确。

问题的解释针对当前语境中不同问法的价值，不是柏拉图原文的一部分，也不是唯一可能的哲学解释。答对率只描述练习记录，不能证明读者已经掌握哲学方法或能将其迁移到新情境。

自动浏览器全流程验证界面是否可操作，不能代替未参与制作的新读者的实际阅读测试。阅读负担、题目难度、反馈是否公平、是否能读懂争议论证，以及长期学习效果，需要另外的人类评估。
