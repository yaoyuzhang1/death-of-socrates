## 复测方法

`pnpm test`检查来源覆盖、可见证据、原问/回应、全部录音散列、插画范围、分页、错误重试及旧存档；`pnpm run build`生成生产正文、书页对照和图片映射并做类型检查。发布还须核实对应提交的工作流成功、线上bundle和最新十卷数据一致、资源可用及实际反馈。

本地浏览器记录保存在`.local/qa`，不随公开站点分发。修改题文、页锚或声音后应按影响范围复测，不能把历史成功直接写成新版本验证。

## 质量边界

426页都纳入电子正文与原版扫描，但没有完成426页逐字学术校勘。新增250页用两个OCR结果比对漏行、脚注位置及可疑字框，重点核对题目页、卷首末和主题边界；仍可能有录入误差。原版页图始终是核查依据。

漫画是场景表现，不是原书插图或论证证据。录音虽为标准普通话声线且文件可播放，自动文本/解码检查不代替每句人工听校。导引、章节、候选选项和解释明确为编辑层，不冒充原典对白。
