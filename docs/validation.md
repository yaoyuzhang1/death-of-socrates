# 验证记录

核对日期：2026-09-07。以下记录区分程序检查、自动浏览器操作与尚未完成的人类体验评估。

## 自动浏览器全流程

使用独立的 Chrome 无头浏览器，通过 Playwright 访问生产构建的本地 HTTP 预览。以全新玩家状态进入，真实点击界面走完五章、二十处场景；没有通过注入完成存档替代这条路线。

这条路线逐场展开全文、留下可选札记、选择回应，再推进到结尾。三个特殊活动均通过界面完成：

- 证言：只选择一位不痛苦的老人，就能够继续；未要求凑出配对证言。
- 分配：选择照料与还债导致超预算时，回应按钮不可提交；保留照料一项即可继续，不强制祭献。
- 寄存物：逐一完成普通归还、明确威胁、信息不足和保管人滥权四个情境，再提交规则。

另外检查了：

- 已提交回应与已推进场景分别在刷新后恢复。
- 结尾可导出包含实际选择和手写内容的札记。
- 导出的进度文件包含完整二十场选择。
- 从札记回溯到第五场，会截去该场及之后的选择。
- 损坏的导入文件不会覆盖当前进度；重新导入刚才导出的完整存档，可以恢复结尾。
- 对话框开启时获得焦点，Tab 不会访问被遮挡的页面控件；Esc 关闭后恢复到触发按钮。
- 桌面 1440 像素、移动 390 像素宽度，以及移动端文字字号整体放大到 200% 的所测页面，没有横向溢出。放大后顶部工具栏能够容纳自身内容。
- 所测完整路线没有控制台错误、未处理的 JavaScript 异常或失败的网络请求。

截图涵盖桌面入口、寄存物活动、结尾，以及移动活动、放大文字和札记。检查中发现的顶部栏文字放大挤叠、对话框关闭后焦点未恢复问题，已修复并重新跑通上述路线。

## 引擎与剧情结构

持续集成共 17 项检查通过。其中，[引擎测试](../tests/engine.test.mts) 的 14 项覆盖有效存档往返、损坏或伪造跳章存档拒绝、旗标累积、替换选择、回溯截断、证言逻辑、资源约束、寄存物活动、来源字段和条件回响可达性；[音轨测试](../tests/voice.test.mts) 的 3 项检查当前剧本与清单的精确覆盖、角色/文本/音频哈希一致，以及没有遗留的过时 MP3。

全部六十个选项均从自己的合法前缀提交并成功推进；三类最终实践方向都能完成并得到不同回望。其余分支的覆盖来自引擎测试，不能据此宣称每条组合路线都已经逐一在浏览器里点击游玩。

测试发现过三条引用了不存在旗标的跨章回响；修正后，所有条件回响均可由此前真实选项触发。

## 真实媒体播放

另使用独立 Chrome 浏览器加载实际发布音轨，完成 18 项播放行为检查。测试记录原生 `Audio` 对象的事件、解码状态、播放时间和真实 MP3 请求；没有用假音频或模拟播放器代替媒体播放。

- 从首页点击进入后，首段普通话自动播放。此 Chrome 实例没有触发“点击恢复”的阻止分支，因此不宣称所有浏览器的自动播放策略均已验证。
- 暂停时媒体时钟停止，继续时从原位置恢复；重听从当前可见段落的首句重新开始。
- 翻到下一段时，单一媒体元素切换到新出现的台词；没有保留另一条旧音轨并行播放。
- 打开札记暂停，关闭后续播原句；如果打开札记前已经手动暂停，关闭札记仍保持暂停。
- 到达选择页后停止对白，不朗读未选选项；确认一项回应后，只启动所选回应的录音。
- 关闭配音后推进场景，没有新增 MP3 请求。
- 将实际媒体播放位置移近句尾后，原生结束事件能够接续下一句；当前段落播放完毕，不自动翻页或替玩家选择。

所测音频可以实际解码，播放时间持续前进，且没有控制台错误或未处理的 JavaScript 异常。测试使用了跳到句尾的方式检查队列结束行为，没有声称完整听完全部录音。

发布清单包含 291 句、17 个角色标签的标准普通话合成录音。音轨总时长 3740.544 秒，约 62 分 20.5 秒，**这是全部分支素材的总和，不是一局的游玩时长**。每个角色标签也不必对应一款独立声音模型。上述文件与播放检查不能代替人工逐字听审或表演评价。

## 范围与限度

这不是新玩家参与的人类体验测试，也不能证明阅读节奏、哲学迁移效果或角色表演已经得到人类评审。后续仍适合邀请未参与制作的玩家，观察他们能否解释自己的理由，并把判断方法用于新的案例。

二十场全流程先关闭配音，验证完整文字玩法；真实媒体播放另行检查如上。没有进行覆盖全部录音的人工听审，不据自动检查断言每个字的读音或角色表演均已达到专业配音水准。

浏览器检查覆盖一款桌面 Chrome 的移动视口模拟，没有宣称覆盖所有手机、屏幕阅读器或浏览器。文字放大检查也不等于完整的无障碍认证。
