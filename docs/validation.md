# 验证方法与质量边界

当前版本采用郭斌和、张竹明1986年版第一至四卷，176书页、八个主题章、47题。旧版555个英译小节与52题的验证报告不用于证明本版。


2026-09-08 的最终构建通过19项引擎/内容测试及 TypeScript / Vite 检查。浏览器从首页真实走完53个阅读单元、47题和8章，3,958项断言通过；176张书页扫描均可加载，复习、导入导出、刷新、书签和390px手机夜间32px阅读检查通过。音频请求、控制台错误、脚本异常及失败请求均为零。正文收录83,934字符（含标点），按校正后的源文件逐字符重建一致。

## 数据与连续性

```sh
pnpm run text:build
pnpm test
pnpm run build
pnpm run preview
```

`reader-content.test.mts`检查176页连续覆盖、PDF/印刷页对应、原问锚点、正确选项为原句、章节转题、短应答和跨页连续文本。将游戏的题前正文、原问、题后正文按顺序重组，必须与校正的源文件逐字符一致，不漏字、不重复、不颠倒次序。

每题必须有三项、唯一正确项、30—100字的题后说明和15—70字的选项反馈；不得恢复题前提示或编辑性章前章后阐释。47题均记录核对的印刷页与PDF页，跨页原问保留完整内容。书页对照必须提供176张原版图，无音频或旧剧情图资源。

## 引擎和浏览器

阅读引擎测试覆盖存档验证、首次记录保留、错答和直接揭示的同一路径、复习与前进、目录开放顺序、进度导入。切换底本后使用新的editionId，旧存档不会被套到新的正文位置。

浏览器验收需要从首页实际点击走完八章，轮流答对、答错和直接揭示；逐题检查答前隐藏、答后原问与说明、两个比较反馈、复习不覆盖首次记录。另查刷新、书签、导出/导入、拒绝损坏文件、纸色/夜间与32px字号、桌面和390px移动视口，以及书页链接和原注。

检查无音频请求、未处理异常、控制台错误和资源失败。浏览器报告与截图针对具体构建，不能由上一版报告替代。上线后还需核查对应GitHub Actions部署成功及公开地址实际返回的底本与题目数量。

## 不能由这些检查证明的事项

字符覆盖证明的是校正后电子源文件与游戏的对应，不证明扫描录入绝无误差。题目和边界经过页图核查，仍不等于整篇逐字学术校勘。对照页保留扫描供复核。

题后说明是编辑文字，不是原典的一部分，也不是唯一可能的哲学解释。模拟移动视口与流程测试不等于全部真机、辅助技术或学习效果评估。
