# 验证方法与质量边界

当前底本为郭斌和、张竹明译《理想国》，商务印书馆1986年版第一至四卷：176书页、八个主题章、53个阅读单元、47题。本次将八章改为独立进入与保存，新增全部完成结算、普通话祝贺与隐藏章节《苏格拉底之死》；主篇底本、分页、题库、解释录音和分章边界保持不变。

2026-09-09并列章节版本验收：56项自动化测试、TypeScript与Vite构建通过。独立浏览器验收完成7项章节与迁移检查、8项结算和彩蛋检查，均无页面异常。章节验收实际从第八章开始，走完该章、在第一章与第八章之间来回切换，并核对首次错答、重答、页码、滚动和书签；另导入真实历史v5存档验证升级。发现的“滚动后立刻打开目录切章，位置尚未写入”问题已修复并复测。快速连点完成最后一个未完成的章后，仍停留全部结算，刷新也能恢复。

彩蛋验收在完成第七章作为最后一个未完成章后，确认真实音频开始播放；关闭配音、停止播放、离开页面均按设置工作。浏览器走完12幕与全部36段回应，核对首次选择不被其他角度覆盖、主篇所有记录不变、实际导出导入、刷新和完成后回访。12张新图全部加载并解码；390px手机、32px夜间文字、插图放大与焦点返回通过检查。

此前的分页版本验收另外通过11项图像、存档、手机排版和复习摘录回归。主篇仍有60个图片文件，59幅出现在273页中，旧港口首图作为保留资源。复习摘录仅用交谈镜头，避免借用较长正文页的配图而提前显示后文例证。

浏览器验收逐页走完首章35页与8题，核对原文，覆盖错答后刷新再答、解释与首次记录、复习、目录回看和旧存档导入。图像验收另检查每页映射、全部压缩文件、放大后焦点恢复、图片加载占位、12段短对话排版、390px手机与32px夜间阅读。

## 正文和分页

正文83,852字符（含标点）重排为226个正文页，另有47个问题页。每页最多12段、760字，实际最长746字。分页综合考虑整段长度、尾页长度、发问与短回应的衔接；长段按标点拆为续页。港口到进入玻勒马霍斯家的p-0019另起一页。逐页片段按顺序拼接，与源正文逐字符相等，包含原问、同次发言的续句和对方回应，不漏字、不重复。

内容测试还检查176页覆盖、跨页段落、译者注不混入正文、47个原问锚点和正确选项。正文SHA-256（去空白）仍为 `bc3e8995d0e02cd3be0ff36cbeb6adfc212f0a5c77c6603a9f255920484c8a19`。

## 引擎和存档

Save v6分别保存八章的已完成单元、停留单元与滚动量，原有页码、首次答案、通过题目、重练、书签继续保留。测试覆盖8→1→8恢复、不同顺序完成全部章节、单独完成第八章不能解锁、章内未通过问题不能借其他章进度跳过，以及旧v5连续进度的逐章分配。彩蛋的12幕首选、探索与完成状态也经过严格导入校验，不能用伪造的半通关记录打开后幕。

v4迁移仍以原页面首个可见字符为锚点，映射到新页内对应原文；旧像素滚动量归零。测试遍历全部743个旧正文页和47个旧提问页，确认阅读锚点与提问前后位置保留。错误选择不能进入后文；随后答对只新增通过状态，保留首次选择。v2/v3迁移仍保留历史开放内容。

完整引擎测试按273页走完八章：每道题先错答，导出再导入仍被拦截，再答对，读完后文才能前进。还检查无效页码、伪造进度、未开放内容、旧存档、复习队列、首次记录和Unicode边界。

## 录音和插画

141条解释录音采用 `zh-CN-XiaoxiaoNeural` 标准普通话声线。47条正确项逐字对应已有题后解释，94条错误项逐字对应所选反馈。测试核对全部文本及文件SHA、完整MPEG帧、文件数量；Chrome已逐条解码，全部非静音，时长5.544—16.296秒。本次新增同声线祝贺录音1条，25.68秒，154,080字节；文字和音频SHA一致，Chrome解码与实际完成点击后的播放均通过。

播放器专项覆盖选项确认才播放、错误只请求所选解释、停止、替换、隐藏页面、退出、提示音和配音分别开关、浏览器拦截及重听恢复。解码和波形检查不代表逐句人工听校。

此次新增的彩色漫画与首批九幅一起以WebP随游戏提供。构建按实际正文顺序解析源段落范围（不能按段落ID的数字排序），为273页固定分配画面；相邻272次翻页都更换图片。例证画面只能出现在对应原文范围内的正文页，47个提问页只使用交谈镜头。测试核对清单、实际文件、SHA-256、不同图片不为同一文件的重命名副本，并检查例证的章节与原文范围。原书176张扫描另存于facsimile目录。制作提示词见[插画说明](art-direction.md)。

## 质量边界

隐藏章独立入口的后续验收：60项自动化测试与生产构建通过，新增6项浏览器检查覆盖直达第一幕、独立存档与刷新、全部12幕、移动端字号与夜间显示、回到主篇、同页链接跳转及损坏体验存档。测试预置真实v5历史存档，体验全程逐字比较主篇存档、主篇页面记录与声音设置未被修改；回主篇后才按正常规则迁移，原答题与阅读状态保留。正常解锁条件仍由默认引擎接口执行。
