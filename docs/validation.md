# 验证方法与质量边界

当前底本为郭斌和、张竹明译《理想国》，商务印书馆1986年版第一至四卷：176书页、八个主题章、53个阅读单元、47题。此次改动合并相邻问答的分页、增加随内容推进的漫画，底本、题库、解释录音与分章文件保持不变。

2026-09-09验收：46项自动化测试、TypeScript与Vite构建通过；当前生产预览另通过11项图像、存档、手机排版和复习摘录回归。51幅新图全部实际接入；连同首批9幅共60个图片文件，59幅出现在当前正文分页中，旧港口首图作为保留资源。复习摘录仅用交谈镜头，避免借用较长正文页的配图而提前显示后文例证。

浏览器验收逐页走完首章35页与8题，核对原文，覆盖错答后刷新再答、解释与首次记录、复习、目录回看和旧存档导入。图像验收另检查每页映射、全部压缩文件、放大后焦点恢复、图片加载占位、12段短对话排版、390px手机与32px夜间阅读。

## 正文和分页

正文83,852字符（含标点）重排为226个正文页，另有47个问题页。每页最多12段、760字，实际最长746字。分页综合考虑整段长度、尾页长度、发问与短回应的衔接；长段按标点拆为续页。港口到进入玻勒马霍斯家的p-0019另起一页。逐页片段按顺序拼接，与源正文逐字符相等，包含原问、同次发言的续句和对方回应，不漏字、不重复。

内容测试还检查176页覆盖、跨页段落、译者注不混入正文、47个原问锚点和正确选项。正文SHA-256（去空白）仍为 `bc3e8995d0e02cd3be0ff36cbeb6adfc212f0a5c77c6603a9f255920484c8a19`。

## 引擎和存档

Save v5分别记录首次答案、通过题目及页码。v4迁移以原页面首个可见字符为锚点，映射到新页内对应原文；旧像素滚动量归零。测试遍历全部743个旧正文页和47个旧提问页，确认阅读锚点与提问前后位置保留。错误选择不能进入后文；随后答对只新增通过状态，保留首次选择。v2/v3迁移仍保留历史开放内容。

完整引擎测试按273页走完八章：每道题先错答，导出再导入仍被拦截，再答对，读完后文才能前进。还检查无效页码、伪造进度、未开放内容、旧存档、复习队列、首次记录和Unicode边界。

## 录音和插画

141条解释录音采用 `zh-CN-XiaoxiaoNeural` 标准普通话声线。47条正确项逐字对应已有题后解释，94条错误项逐字对应所选反馈。测试核对全部文本及文件SHA、完整MPEG帧、文件数量；Chrome已逐条解码，全部非静音，时长5.544—16.296秒。

播放器专项覆盖选项确认才播放、错误只请求所选解释、停止、替换、隐藏页面、退出、提示音和配音分别开关、浏览器拦截及重听恢复。解码和波形检查不代表逐句人工听校。

此次新增的彩色漫画与首批九幅一起以WebP随游戏提供。构建按实际正文顺序解析源段落范围（不能按段落ID的数字排序），为273页固定分配画面；相邻272次翻页都更换图片。例证画面只能出现在对应原文范围内的正文页，47个提问页只使用交谈镜头。测试核对清单、实际文件、SHA-256、不同图片不为同一文件的重命名副本，并检查例证的章节与原文范围。原书176张扫描另存于facsimile目录。制作提示词见[插画说明](art-direction.md)。

## 验收命令

```sh
pnpm test
pnpm run build
pnpm run preview -- --port 5189
```

浏览器验收应在当前构建逐页走完首章，并覆盖：错答→刷新→重答→答对、动画和实际音频、翻页焦点、原文顺序、返回首页与最新进度、复习原问分页、旧存档导入、390px手机、32px与夜间、减少动态效果、插图放大及原书核对窗口。预期模拟的资源失败单独记录；正常流程不得有控制台错误、未处理异常或失败请求。

此前长文和短页版本的报告仅保留为历史记录，不替代本次浏览器验收。公开发布还须单独核查部署状态、页面构建版本、全部漫画资源及实际音频播放。

## 质量边界

字符覆盖证明校正后的电子稿与游戏一致，不证明扫描录入绝无错误，也不代表逐字学术校勘。题后解释是编辑文字。漫画是场景表现，不是原书插图或论证证据。模拟移动视口、自动化流程与录音解码不能替代全部真机、辅助技术或逐句人工听校。
