# 原文回顾问题与阅读节奏

在47个“苏格拉底的下一问”之外，另有38个简短的原文回顾问题，存放于 `content/learning/checks.json`。它们位于现有文字页的末尾，检查刚读到的主张、人物立场、比较关系或论证目的。回顾题本身不改写原典；本轮核心题另行审查，保留47题的ID与正确选项ID，其中46题保留原有原问，1题改选同段带明确限定的原问。总分页仍为273页。

原有互动题要求辨认一个更好的提问，回顾问题则帮助确认已经读懂的内容。这两种记录应分别保存；回顾题不能覆盖核心题的首次答案，也不改变八章各自的阅读记录。

## 本轮语义审查

38题全部连同所指的可见正文通读，首轮实改30题，随后再次检查并修正三个问题：牧羊人题有两个可被原文支持的答案；把护卫者的幸福问题缩写成了享乐；未给出论据便称提问“有力”。现在分别检查照料牛羊与最终受益者、通常的幸福条件与履行职责、提问究竟检验了哪一步。评价原文中的论证，不等于替它宣布结论成立。

特别保留人物立场的层级：格劳孔与阿得曼托斯是在加强反方挑战，色拉叙马霍斯是在反驳技艺受益者的解释。题目要求辨认他们实际主张了什么，不把人物代述的立场当成读者应接受的结论。所有正确依据须在本页已读片段中可见，不能要求靠尚未出现的后文补齐。

主篇38题与隐藏章12题共用150条解释录音；正确项读本题解释，错误项读所选反馈，按本轮文字更新。录音生成完成与实际交互验收是两步，当前完成状态以[验证说明](validation.md)为准。核心题、隐藏章与正文修正的汇总见[原文与提问审查](source-question-review.md)。

## 分配依据

先用当前 `makeReadingPages` 为全书建立实际页面目录，再统计各章阅读量与核心互动之间的间隔。新增位置优先选择长段讨论中的完整意思落点；在能讲清一个局部关系的位置收束，避免只因翻到某个固定页数就插题。

第四章只有1个核心提问，却有约8,400字符的长论说，因此增加5个回顾点；第六章阅读量最大，而且故事审查、叙述、音乐与体育中存在长间隔，增加13个。第一、第三章原有提问已经密集，各仅增加2个。分配依据是实际阅读负荷和可理解的论证片段，没有把各章补成相同的题数。

## 锚点与来源

每个条目具有：

```text
id, chapterId, pageId, sourceIds,
prompt, options[{id, text, feedback}], correctId,
explanation, sourceRef
```

`pageId` 使用当前分页的稳定ID，且必须对应文字页。`sourceIds` 只列该页实际出现的原文段落ID；长段落可能拆成多个片段，问题和反馈依据的是当前页面已经显示的片段，不因段落ID相同而借用后页内容。`sourceRef` 给出原书印刷页与小节，便于回到扫描核对；跨页长段的出处范围可能宽于这一片段。

38个页码互不重复，全部与核心问题页至少相隔一个文字页，没有紧挨核心题页再插入一道回顾题。每题有 `a`、`b`、`c` 三项，正确项固定关联内容；实际显示顺序由界面负责。每个错误项有独立说明，指出具体混淆，而非仅显示“不对”。

设计时重点区分了以下关系：

- 人物复述反方理由，与人物自己的立场。例如格劳孔和阿得曼托斯加强反方挑战，并不代表他们已赞成不正义。
- 提出一个线索，与已经完成证明。例如城邦职业齐全以后，正义的所在仍待寻找。
- 比拟中真正比较的对象，与故事的装饰细节。例如牧羊人之喻问的是谁受益，识字之喻问的是能否辨认不同呈现中的同一品质。
- 本段设想中的规范，与脱离语境的一般命令。例如故事、音乐、虚假及身体训练的讨论，题目始终指向原文正在构造的城邦和教育方案。
- 本身的性质、它的名声及外在报酬。第四章的回顾点围绕这三者，避免将长论说只变成戒指故事的细节测验。

这批内容已核对页面ID、章归属、可见段落锚点、每题三个不同选项、正确项引用、非空反馈与重复页面，并检查与核心题页的距离。表中当前字符统计采用本轮校正后的83,876字符电子正文。逐题语义核对采用郭斌和、张竹明译文片段，问题文字与解释是项目编辑内容，不能标成原译文。这也不等于已完成176页逐字学术校勘。

统计与锚点核验不代替界面验收。作答后的展示、错答重试、配音、键盘、进度保存与公开站点加载，需要在接入后的实际构建另行检查。
