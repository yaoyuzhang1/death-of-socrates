# 八章并列阅读与存档

第一至第八章从首次进入时全部开放。玩家可以先开始一个新的章节，稍后再回到另一章原来停留的位置。章节之间不再以编号前后作为进入条件；同一章节内部继续按原文顺序推进，追问仍需重新选对后才能阅读后文。

## 阅读结构

首页与目录中的章标题都可进入章节。未开始的章从第一节第一页进入；已开始的章恢复自己记住的小节、页码与滚动位置。章内的已完成小节可以回看，目录标记尚未读到的小节。回看后，“回到本章最新进度”回到当前章节已推进到的位置。

切换章节不会清除或重新初始化其他章的记录。每章完成后出现本章小结，玩家回到八章目录，自行决定下一章。只有全部八章各自完成，才进入八章结算与隐藏章节；单独完成第八章不触发全部通关。

主篇内容规模保持为83,852字符、53个阅读单元、34小节、8章、47题、273个页面（226个正文页与47个追问页）。主篇的60幅漫画、原文页图、47条正确解释及94条错误反馈继续使用。结构改动不重写郭斌和、张竹明译文，也不重新判断已经保存的首次答案。

## v6保存结构

存档版本为 `6`，正文版本标识保持原值。浏览器继续使用原存档入口，读取后验证并转换旧数据。当前章与全局完成数量保留在顶层，以便界面与总体进度读取；每章另有 `chapterProgress` 条目。

| 记录 | 内容与保留方式 |
| --- | --- |
| `chapterProgress[chapterId]` | 本章完成的阅读单元数量 `completed`、上次停留单元 `cursor`、是否开始 `started`、滚动位置 `scroll`。`cursor`采用主篇全局单元索引，必须属于本章。 |
| `pages` | 每个阅读单元内的页码，切换章节继续保留。 |
| `answers` / `resolved` | 首次答案与已经通过的追问分开保存。先错后对只增加通过状态，不替换首次选择。 |
| `reviews` | 重练次数、答对次数、最近选择与时间，继续独立于首次记录。 |
| `bookmarks` / `settings` | 跨章节书签、字号与阅读背景。 |
| `reading` / `hints` | 兼容已有阅读位置及旧版提示记录。 |
| `bonus` | 隐藏章节当前场景、完成状态、每场首次选择及已探索角度，与主篇记录分开。 |

顶层 `completed` 等于八章已完成单元数之和，不再表示从全书开头连续推进了多少单元。某个单元是否可进入，依据它在所属章节内的位置与该章已完成数量判断。进入第六章不能让第一至第五章自动标成已读，也不会使此前在其他章留下的记录失效。

## 旧存档转换

v2、v3、v4、v5存档均可迁移。版本与正文标识通过验证后，旧版连续的已完成单元分别归入所在章节：已经走完的章标记完成，正在进行的章保留其有效位置，尚未读到的章从章首开始并开放进入。

v5页码直接继续使用。v4的旧短页先按原文片段位置对应到现有分页；v2和v3延续已有阅读批次转换规则。首次答案、历史揭示记录、已保存的重练、书签和阅读设置按原规则保留，不将旧版原文重新抽题或重排。已有全部完成存档迁移后满足八章解锁条件，隐藏章节初始状态为空。

导出包含完整v6存档：八章的独立进度与隐藏章节都在同一文件内。导入按同一结构验证后恢复整份快照；不逐章合并来自不同浏览器的记录。阅读设置中的重新开始功能会清除当前浏览器的整份阅读与答题记录，日常切换章节会保留它们。

## 八章结算与祝贺

八章都完成后，结算页显示完成章数、已走过的追问数、首次选中原问的数量与每章阅读足迹。结算不要求全部追问一次答对；原来的错答重试、选对后阅读原问与回应仍是章内推进规则。可以从结算页重读某章或进入重练，所有首次记录继续保留。

新增1条标准普通话祝贺录音，采用微软 `zh-CN-XiaoxiaoNeural` 声线，文件与精确文本见 `reader-public/audio/completion/`。完成八章时，在配音开启状态下播放；结算页提供播放和停止入口。关闭配音或离开对应页面时停止。新增录音与原141条解释一起作为静态文件分发，游玩时不再向语音服务发送文本。

## 隐藏章节与探索记录

《苏格拉底之死》包含12场、每场3个角度，共36段可选择的回应，另有12幅新漫画。它通过《申辩篇》《克里同篇》《斐多篇》的材料，呈现正式控告、申辩与量刑、拒绝出逃以及最后的谈话。对白经过中文戏剧化改写，来源说明见[death-sources.md](death-sources.md)，不属于商务印书馆郭斌和、张竹明《理想国》译文。

场景依既定历史顺序开放；每场至少探索一个角度，便可继续下一场。选择没有正确或错误标记，不提供救活或提前杀死苏格拉底的另类历史路线。玩家可回看已经走过的场景，探索其他角度。最后一场作出选择后，显式结束对话，查看札记和首次选择回顾。

`bonus.choices[sceneId]`记录第一次选择，后续探索不覆盖它。`bonus.visited[sceneId]`记录已探索的不同选项，重复查看同一选项不增加数量。`bonus.cursor`记录当前场景，`bonus.completed`记录是否已经合上完整对话。这些记录不会进入主篇47题的首次正确率或重练队列。

本说明描述实现的数据结构与玩法，不代替实际浏览器和公开部署的验收记录。
