# 隐藏章节《苏格拉底之死》插图

本组12张宽幅单格漫画分别对应 `content/bonus/death.json` 的12个场景。使用内置 image_gen 逐张生成，全部为新图。参考现有《理想国》插图的人物设计和色彩墨线风格，不改变隐藏章节的文本内容。

每图1672×941，发布文件为 `reader-public/illustrations/bonus/<场景ID>.webp`。PNG原稿保留在本地工作目录，WebP质量83，仅进行格式编码。资源映射在 `content/art/bonus-art.json`。

制作时核对了全部场景段落：庭审部分依次表现控告、盘问与判决；牢房部分由拂晓的来访走向最后一天和临终守候。法律的拟人陈词通过两位说话者表现，不画成实际显现的女神。死亡现场未指定柏拉图在场；杯子只作历史场景道具，不表现毒药制作或身体症状。插图是文学阅读辅助，建筑、器物与人物容貌属于艺术设计，不是考古复原。

已逐图查看人物、构图、肢体与文字禁用要求。所有图像都无文字或对白框，主体人物位于画面中部。
