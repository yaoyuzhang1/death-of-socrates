# 全书阅读导引与理解检查审查

## 策划判断

导引的目的，是让初读者知道这段讨论正在做什么、从哪里开始，而不是提前提供题目的正确选项。全书的主线是正义的生活本身是否值得选择；城邦的构想是寻找与说明正义的方法之一，城邦与个人的对应还需另行论证。理解这套论述与赞同所有制度安排，是不同的任务。

本轮未取得可核验的直接玩家评论。以下设计属于项目中的体验审查与独立策划判断，不声称代表玩家共识。

## 入门与选择

- 首页用一段话说明全书追问，并将人物与玩法放进可展开的入门说明。
- 全部二十章均可直接进入；章号始终保持原典次序，不因按兴趣筛选而重新编号。
- 按卷与按主题两种选择方式并存。每章给出范围、原文长度、讨论疑难与独立进度。
- 三条短路线只推荐若干完整主题，不构成必修关卡，也不增加支线剧情。
- 每卷与每章都有独立导引数据，存于 `content/reading-guide.json`。主题标题、路线、章前导引与章末回顾均明确属于编辑内容。

## 章前与章末的不同责任

章前只补必要背景与阅读对象，例如辨认同一场聚谈、区分护卫者与全体居民，或区分挑战者的复述与个人信念。正文题前不追加解题提示。章前细读建议可展开，也能在阅读途中通过“本章导引”查看。

章末用三步回顾论证如何推进，再标明尚可检查的前提、类比或争点。回顾不把每一项苏格拉底的结论写成已经得到普遍证明的事实。第五卷的教育与共同生活方案保持护卫者的角色范围，第十卷使用本底本的“厄洛斯”译名。

人物侧栏说明同一次聚谈仍在玻勒马霍斯家。太阳、航船、洞穴与命运故事是讨论内容，而非主人公移动到了这些新地点。第六卷前半和第八卷的接话者按实际正文标为阿得曼托斯，避免全部默认为格劳孔。

## 新增五十一条理解检查

逐项核对了 `.local/guo/fullbook/draft-pages.json` 中相应印刷页的上下文；初稿四十九题的九十八个错误选项经过修改，最后补入两题后，每个错误选项仍有针对其误读的反馈。内容位于 `content/learning/fullbook-check-drafts.json`；生成程序读取每条第十、十一项的专属错误反馈。

重要修正包括：

- 出洞后的逐步适应应对应274页；275页讨论的是返回洞穴后适应黑暗，不能混作同一场景。
- 洞穴教育的证据定位到“作为整体的灵魂必须转离”，不再用泛泛的“灵魂”搜索。
- 必要欲望的定义有两类标准：不可避免，**或**满足后有益；不误写为每种欲望必须同时满足二者。
- 民主政制的锦绣衣裳比喻在332页；用词不采用与原句不符的“花样”。
- 三类人生的明确区分在368页，计量校核显现的证据在400页，恢复正义的美名与报酬的证据在415页。
- 梦中欲望的量词按原文“每一个人”理解，并明确欲望显现与醒时实行行为不是同一件事。
- 归还正义的报偿，以“苏格拉底认为前面的比较已经进行”说明讨论层次，不替读者宣布前文已获得不可争议的证明。
- 同一错误反馈不再普遍套用“换掉对象”或“扩大结论”；每项说明它具体倒置、遗漏或混淆了什么。

全书生产分页完成后，又逐页阅读了最初四十九条题目实际对应的阅读页，分别检查正确项、两个错误项与解释是否由已经可见的原文支持。七条无法落在合适阅读页的题目改选了同章的独立理解点：众人认识与哲学非难、定义中循环使用“善”、卷八重返被打断的议题、相对可敬与内在和谐、僭主的心灵贫穷、整体心灵的自主、缰绳与嚼子的用途判断。它们保留题目ID，内容及证据同步改写。

这一遍检查还修正了两个分页问题：儿童的强迫学习题定位到完整比较身体劳动与学习的那一页；“极端自由”的题目不再用泛泛的“自由”搜寻，避免误落到财产自由处置的段落。关于避墙、感觉判断、快乐比较的反馈也去掉了依赖未来页细节的说法。平静的题目根据实际页改成先区分不痛不乐的中间状态，书页准确标为371页。

最终节奏审查在两个较长空档补入理解检查，同时冻结已经审定的四十九题：208页检查希腊战败者禁奴主张的理由与对象范围，不误写成适用于所有敌人的普遍禁令；295页检查天空图画的辅助说明作用，不把作者的理性教育目标直接当成现代天文学的评价标准。两题的证据都完整呈现在各自阅读页，分别为两个错误项提供解释，不增设虚构的苏格拉底对白。

生成程序沿原始段落继承印刷页标记，用可见片段的原段落ID核对指定书页；找不到指定页时直接报错，不再选另一个含同词的页面。五十一题分布于十二个新增主题章，每章四至五题，各自位于不同阅读页，且不会紧邻核心问题页。逐页证据留在本地审查记录 `.local/qa/final-learning-visible-evidence.json`，生成后的正式题目在 `content/learning/checks.json`；旧三十八条理解记录保持原ID，主篇共八十九条理解检查。

## 进度与奖励

前八章完成即保留《苏格拉底之死》的解锁资格；追加十二章不会把已有彩蛋锁回去。完整二十章另有全书结算。八章里程碑和全书完成采用不同祝贺录音。

理解检查存档与私人隐藏关体验接受明确的旧版ID到全书版ID迁移。迁移保留首答、重答、正确状态与隐藏记录，不接受未知版本伪装成旧版。旧备份的前八章记录保留，新章节初始化为未读。
