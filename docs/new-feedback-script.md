# 新增理解检查配音文稿

这份文稿列出50道检查的150段解释，便于逐项审阅。题干和选项只用于说明位置；拟发送给语音服务、实际朗读的内容仅为每项“配音文字”。

使用标准普通话声线 Microsoft zh-CN-XiaoxiaoNeural，语速-3%。选对后朗读该题总解释；选错后朗读所选选项的反馈。


## 正篇阅读检查（38题）

### 1. 苏格拉底提出用劝说离开时，玻勒马霍斯指出了什么困难？

位置：书页1—2 · 来访与聚谈。题目编号：reading-willing-listeners。

**选项 A（正确）** 对方若不愿听，劝说就难以展开。

配音文字：

这段玩笑把劝说的处境摆了出来：苏格拉底愿意讲理由，对面却表示不肯听。

**选项 B（需重答）** 苏格拉底还没有说明返程路线。

配音文字：

这里争论的是愿不愿听劝，并没有把返程路线当作困难。

**选项 C（需重答）** 必须先证明火炬赛马不好看。

配音文字：

比赛是随后挽留他们的理由，并非玻勒马霍斯对劝说提出的困难。

### 2. 再次谈到“欠债还债”时，双方仍保留了哪项限制？

位置：书页6—7 · 所欠之物与技艺。题目编号：reading-return-conditions。

**选项 A（需重答）** 只要称它为欠债，何时归还就都正当。

配音文字：

玻勒马霍斯同意原主头脑不正常时不该还，尚不能把归还说成无条件规则。

**选项 B（正确）** 原主头脑不正常时，不应不加区别地归还代管之物。

配音文字：

这段没有抹去欠债关系，而是保留了归还时原主状态这一限制。

**选项 C（需重答）** 代管之物从来不能算作欠债。

配音文字：

苏格拉底明确承认代管之物“的确是一种欠债”；争议在归还的情形。

### 3. 色拉叙马霍斯在这一页终于提出的正义定义是什么？

**选项 A（需重答）** 正义就是对求教者表示感谢。

配音文字：

本页定义指向“强者”的利益，没有声称所有人的利益相同。

**选项 C（正确）** 正义就是强者的利益。

配音文字：

先辨认是谁提出了什么主张，才能接着看苏格拉底怎样检查它；提出定义还不等于已经证明。

### 4. 在这里所说的“严格意义”下，医术寻求的是谁的利益？

**选项 B（需重答）** 医术自身的利益，因为它也需要另一技艺补救。

配音文字：

苏格拉底恰在排除技艺不断需要另一技艺补救的推展。

**选项 C（需重答）** 任何付钱者的利益，与治疗对象无关。

配音文字：

这一页从技艺及其对象来讨论，没有用谁付钱替代身体这一对象。

### 5. 色拉叙马霍斯用牧羊人喂肥牛羊来反驳什么看法？

**选项 C（需重答）** 反驳牛羊需要食物，认为它们能自行长壮。

### 7. 按这里暂时列出的比较，正义者与不正义者想胜过谁？

**选项 C（需重答）** 两类人都只想胜过同类，不想胜过异类。

配音文字：

### 8. 关于有知识的人，本页同意了怎样的判断？

**选项 C（需重答）** 有知识就一定要超过所有其他有知识的人。

配音文字：

本页的判断是同样情况下彼此相似，并非以压倒同类为知识的标志。
