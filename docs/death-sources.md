# 隐藏章节《苏格拉底之死》：文本与改编说明

本章将《申辩篇》《克里同篇》《斐多篇》中有关审判、拒绝逃走和死亡的材料，重组为12场中文互动叙事。它在第一至第八章全部完成后解锁，属于本项目原创戏剧化改编，**不是郭斌和、张竹明《理想国》译文的延长章节**。主篇文本、原有47题的首次记录、彩蛋谈话选择与新增理解判断分别保存。

人物对话按原作论证改写，场景连接、动作细节和提问入口由本项目安排。每场先选择想听的谈话角度，三个选项均有可阅读、可朗读的回应；这个选择不计对错，也不改变历史结局。每场可再听其他选项，固定叙事始终由审判走向牢房。故事不以选择分数衡量死亡，不把任何一种逃生选择变成玩家的道德考试。

回应之后另设一处理解判断，共12处，题目位于 `content/bonus/checks.json`。它们检查当前已读内容，例如旧日传闻与正式控告、有罪与量刑、罚金提议与法庭裁决、记载与解释的区别；不要求玩家赞同人物立场。判断有明确答案与逐项解释，答错可重试，答对后继续新场景。这些判断与主篇新增38处页末检查共用独立记录，原有47次核心追问保持不变。已通关的旧版彩蛋仍保留通关状态，可在结尾主动开始“挑战十二幕”。

## 核对底本

- [柏拉图《申辩篇》，Benjamin Jowett 英译，MIT Internet Classics Archive](https://classics.mit.edu/Plato/apology.html)。核对17a–42a的申辩顺序、控告、盘问、两次表决及处罚提议。
- [柏拉图《克里同篇》，Benjamin Jowett 英译，MIT Internet Classics Archive](https://classics.mit.edu/Plato/crito.html)。核对43a–54e的来访、逃走劝说、不以恶报恶和拟人化法律陈词。
- [柏拉图《斐多篇》，Benjamin Jowett 英译，Fordham Ancient History Sourcebook](https://sourcebooks.web.fordham.edu/ancient/plato-phaedo.asp)。核对叙事框架、祭船、最后一天的反驳、告别与死亡。该文本依据公版历史译文，本项目未打包复制其网页、电子排版或全篇英译。
- [《斐多篇》57–61，Harold North Fowler 英译，Perseus / Scaife ATLAS](https://atlas.perseus.tufts.edu/library/passage/urn%3Acts%3AgreekLit%3Atlg0059.tlg004.perseus-eng2%3A57-61/)。交叉核对祭船与延期、柏拉图不在场、脚镣解除及哲学与自行结束生命的区别。
- [《克里同篇》51–52，Perseus / Scaife ATLAS](https://atlas.perseus.tufts.edu/library/passage/urn%3Acts%3AgreekLit%3Atlg0059.tlg003.perseus-eng2%3A51-52/)与[53–54](https://atlas.perseus.tufts.edu/library/passage/urn%3Acts%3AgreekLit%3Atlg0059.tlg003.perseus-eng2%3A53-54/)。交叉核对“说服或服从”、居留及约定论证、克里同最后的回应。
- [《申辩篇》，Harvard Center for Hellenic Studies](https://www-current.chs.harvard.edu/primary-source/plato-the-apology-of-socrates-sb/)。辅助核对斯特凡努斯页码，特别是32c–e的莱昂事件、35e–38b的刑罚阶段。
- [《斐多篇》，Gwenda-lin Grewal 英译，Harvard Center for Hellenic Studies](https://www-current.chs.harvard.edu/primary-source/platos-phaedo-trans-gwenda-lin-grewal/)。仅辅助核对118a末语中的复数“我们”与交代偿还的意思；未借用该现代译本的长篇文字。

数字如“24b–26a”采用斯特凡努斯页码，指向作品内部的位置，与所用中文书籍的印刷页码不同。主篇采用的商务印书馆1986年《理想国》不包含这三部作品，故本章另列资料，未把改写标成该中译本原文。

## 处理历史与哲学解释的边界

苏格拉底在公元前399年受审、被处死属于事件背景；柏拉图的文本则带有作品自身的选择、结构与人物声音。这里没有伪造一份完整控方演说，也没有替陪审员编造独白。关于名声、妒恨和反对者动机的叙述尽量归在苏格拉底的申辩立场下，避免把它们当作每位投票者都承认的事实。绝对票数并非体验所需，正文仅区分有罪裁决与死刑裁决。

《克里同篇》的“法律”是苏格拉底想象并代为说出的声音，并非牢房里出现的实体或独立审判者。其不逃走结论依靠不作恶原则及有关约定的进一步论证。与《申辩篇》拒绝捕捉莱昂的材料并读，可以看见问题的复杂性；本章既保留法律陈词，也不将它改写成对任何政权、任何命令的无条件服从口号。

《斐多篇》58a–c解释执行延期，59b写到柏拉图可能因病缺席。因此死亡场景不安排柏拉图在场记录。苏格拉底被处死的机制以饮下执行刑罚的毒药交代，身体变化遵循117e–118a的叙事，不增补植物辨认、用量、配方或操作步骤，也不将文学记述包装成现代医学报告。

118a末语中的阿斯克勒庇俄斯与医治有关；文中没有当场说明偿还公鸡究竟所为何事。本章独立改写这句短语，并核对复数“我们”，但不替它指定“整个人生是一种疾病”等唯一解释。《斐多篇》的灵魂论证远长于本章取样；和谐与织工比拟在此是留下问题的入口，原作后面的回应仍需回到原文阅读。

## 内容核验

固定12场景，顺序与保存状态共用的 ID 一致；每场3个 `a` / `b` / `c` 谈话选项，全部具有具体回应和来源说明。戏剧正文 `death.json` 没有正确答案或分数字段；独立的 `checks.json` 才保存12处理解判断的答案与解释。全量对话、选择及回应约4,800个汉字，不含新增判断；只走一条谈话选项路径时，每场约180–210个汉字，另含按钮文案、标题与出处。不同角度可随时重读，全部读完也不会改写主篇47题的首次作答。

左侧资料说明地点、主要人物与作品的叙述框架，并随场景更新；“法律”明确标为苏格拉底设想的声音，不列作到场人物。人物介绍不提前宣布朋友的下一步行动，也不把《理想国》的聚谈背景带入公元前399年的法庭与牢房。

119段标准普通话录音覆盖42段场景正文、41段人物回应与36段选项说明，逐段使用原有改编文字，不添加台词。场景正文由玩家手动开始；确认选项后仅朗读该角度的回应与说明。苏格拉底使用云希，克里同及其他男性使用云扬并区分语速，旁白与说明使用晓晓。完整清单见[隐藏章节人物配音](../reader-public/audio/bonus/README.md)。另有12处判断与主篇38处检查的150条标准普通话解释录音，只在确认对应选项后播放，准确文字和文件清单见[理解检查配音](../reader-public/audio/study/README.md)。

阅读进度继续采用v6分章结构；理解检查独立存储首次与最近选择、尝试次数和通过状态。导出时以 `republic-reading-backup` 第1版封装将阅读和检查记录装入同一个文件。新备份恢复两部分；旧版纯阅读文件只恢复它包含的进度，保留本地已有检查记录。切换章节、重听与重练均不会抹去首次记录。
