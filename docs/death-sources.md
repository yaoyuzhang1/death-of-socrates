# 隐藏章节原作来源

隐藏章《苏格拉底之死》依据柏拉图《申辩篇》《克里同篇》《斐多篇》的历史英译节译与节述。主篇所用的郭斌和、张竹明译《理想国》1986年版不含这三篇；隐藏章文字不署作郭、张译文。

主要底本为Benjamin Jowett：[《申辩篇》](https://classics.mit.edu/Plato/apology.html)、[《克里同篇》](https://classics.mit.edu/Plato/crito.html)、[《斐多篇》](https://sourcebooks.web.fordham.edu/ancient/plato-phaedo.asp)。118a末语的复数“我们”另据[Henry Cary历史英译](https://www.gutenberg.org/files/13726/13726-h/13726-h.htm)核对并标注差异。未将其他现代中文译本或现代英译的大段文字纳入隐藏章。

逐段出处、原作锚点、类型及文字散列见[来源映射](../content/bonus/source-alignment.json)，逐幕修改及判断依据见[审查报告](audit-bonus-source.md)。数字如“24b–25a”为作品内部的斯特凡努斯页码，不是主篇译本的印刷页码。

## 本轮调整

- 12幕、36个阅读角度保留；人物对白采用可定位的原作节译，编辑连接与说明单独标记。149条映射包括59段固定正文、53段可选回应、36段说明及1段结束文字。
- 纠正苏格拉底设想的答话被换成克里同独白；区分假设条件、有罪判断、刑罚提议和最终裁决；跨越原作长段论证时明确标出省略。
- 12处独立理解判断均列出固定正文依据，无论选哪个角度都可以作答。理解他的论证与同意该论证分开，题目不要求赞同全部立场。
- “法律”是苏格拉底设想的声音；厄刻克拉底在《斐多篇》的转述框架中听斐多叙述，不是牢房来访者。末语不附会成原作未明说的唯一象征解释。

## 阅读、声音与图像

148段普通话录音覆盖固定正文、可选回应及说明。场景正文由玩家开始朗读；选项回应只在确认后播放，逐字匹配审定文字。结尾斐多评价保留文字阅读。另有12处判断与主篇38处检查的150段普通话解释，选错需重答，保留首次记录。清单分别见[人物配音](../reader-public/audio/bonus/README.md)和[理解检查配音](../reader-public/audio/study/README.md)。

漫画为本项目的视觉重构，不能代替原作出处或充当历史现场证据。原作本身是柏拉图的哲学作品，节选不声称还原完整庭审实录，也未完整收录《斐多篇》的灵魂论证。

阅读继续采用八章独立进度。隐藏入口、理解记录和正常主篇进度分开保存；导出文件包括主篇与理解记录。重听、重练和章节切换均保留首次选择。
