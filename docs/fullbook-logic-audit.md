# 全书扩展的哲学与互动逻辑审查

2026-09-27。审查既有第一至四卷47道核心提问、38处理解检查及存档引擎，并在下方逐题记录第八至十卷的24道新增核心题。后六卷的整体转写、正文覆盖与题目定位另见[全书原文审查](fullbook-source-audit.md)。本报告沿用2026-09-09已完成的源文审查，不为增加改动量重写已经准确的题目。

## 反馈依据与策划判断

主任务的公开检索目前没有发现可核实的游戏玩家评论，GitHub公开issues为空。因此，下列条目是根据游戏本身与本轮用户目标作出的独立审查，不冒充网上玩家的意见。日后具体帖子或评论到达时，须另行核对意见所指版本与复现条件。

## 既有题库复审

47道核心题按原问、较弱备选、逐项反馈、整体解释及所在段前后文一起检查；38道理解检查通读并检查它们是否分清发言者和论证阶段。整体保留原问、题号、正确选项ID、定位和既有页序。前轮已将解释限制在人物接受的前提与局部推论，不需全面再写。

本轮明确修订一处：`book3-believing-the-story`，415c，印刷129页、PDF140页。较弱选项a原反馈称“不能由效果代替可信性的考察”，容易把“能否使人相信”混为“值得相信或确实真实”。原问是“你看你有没有办法使他们相信这个荒唐的故事？”，随后格劳孔比较当代人与后代。因此改为：“赞成分工与相信出生故事是两回事；只确认赞成的效果，还没有说明人们会不会相信故事，以及怎样使他们相信。”原问、备选问句及正确ID均不变；仅这条录音需要同步。

重点保留而非加写的处理：

- `book1-what-harm-means`及`book1-justice-opposite-effect`，335b–d，14页：把受害与德性受损联系起来是待检查的类比前提，解释不能宣告现实受害者必然品德变坏。现有反馈已明确这一边界。
- `book2-larger-field`，368e，57页：“城邦比个人大”只是已提出大小字比喻的一步，不能推广成问大小天然更好。导引需要保留这项方法前提，现有解释已说大小不保证两者的正义相同。
- `book2-good-and-cause`，379b，74页：由不作恶到不成为恶因是因果环节，仍依赖双方的善神观。现有说明没有把它当成无需论证的普遍事实。
- `book3-death-and-courage`，386b，82页：怕死是否妨碍勇敢与不怕死是否足够勇敢是不同条件，不把后者这种有效问题说成无意义。
- `book4-ordinary-test`，433e，155页：问题带引导性，双方认可司法目的提供局部支持；它不穷尽现实司法的所有目的。
- `book4-same-form`，435a，157页：前轮已把实际考点移至“仅就正义的概念而论”的限定原问，并将泛问作为此前正文。本轮维持，避免以同名推出所有方面相同。
- `book4-spirit-reason`，440e–441a，167页：帮助理性与本身属于理性须分开，国家三分不能独自证成灵魂三分；现有解释保留后续证明任务。

## 新卷的选题标准与节奏

第八至十卷每卷安排约8道核心题，分成两个主题章各约4题。优先选择有明确比较对象或论证空缺、原问独特且在题内表达足够限定的句子。短小“是不是？”若离开前文便不能评价，不宜只因作者身份选为核心题。

新卷应同时包含分类、必要条件、推论检查和类比范围等不同问题。较弱项提出真实而相关的旁问，逐项说明它目前还缺哪一步，避免明显荒谬、长度线索、反对意见自动判错或先接受未证明结论。理解检查则可辨析谁的观点、假设何在、结论是否已经成立以及寓言与论证的区别。

每个新主题章安排4道核心题。后六卷另增51处理解检查：共同生活、辩证法和最后的故事章各5处，其余新章各4处。实际位置优先依论证转折调整，而不是把两种练习全部挤在核心题附近。题间允许几页连续阅读，长寓言或叙述应先保存一个完整场景，不机械切成多次答题。

最后一轮节奏检查针对共同生活与辩证法中的长阅读空档补了两处理解检查，没有移动原有核心问题。`learn-full-community-war-limits`依208页对希腊人相互奴役的禁令，分清同族团结和外部危险的理由与限定对象；“暂时奴役”的错误项是额外添加原文没有规定的期限例外，不会构成另一项正确理解。`learn-full-dialectic-astronomy-model`依295页的天空说明图及几何设计图类比，区分图像的辅助作用与绝对比例知识；既不以精美图像保证真知，也不把辅助作用完全取消。解释将这套目标归于原作，不当作现代天文学标准。两题的题干、选项与反馈独立复核通过。

第十卷的四道“命运与回报”核心题位于409至416页，保留原作由不朽论证到重新纳入报酬的次序。417页以后厄尔故事的长篇叙述没有被伪造为苏格拉底的提问。该部分由主任务在抽签与选择、奥德修斯的普通生活和结尾处配置理解检查，考察故事说了什么及其论证地位，不把神话宣示当作已经证实的知识。

交叉审查时采纳两项修订：`book8-intermediate-regime`的较弱选项不再提前泄露原问以后才介绍的公餐安排，改为只取前文金银集团愿望进行片面归类；`book9-desires-and-resources`的两个较弱项从泛问宴饮身份与羡慕，改成检验“强烈就必要”和“最早就优先”的类别混淆，避免重复使用财富、声誉作为容易排除的线索。没有把“资源固定而欲望增长，是否还能维持生活”这一有价值的检验问题塞进错项；它能推进本段推论，若强行判差会制造双正确。

另外改进`book8-character-evidence`与`book8-democratic-life`的较弱项：问契约赞扬是否可靠、问财富和掌权机会，本身都能是适切的调查，不宜因它们不在苏格拉底原句中就判差。前者改为未经核实就转去传播诚实名声，后者改为直接按最富者的财富给所有人生活排序，反馈指出其未说明的依据或范围。也不将“名声能否独自支持定论”这种有效的批判问题判错。

目视核对另外发现六项电子转写问题，已将扫描证据交给原文处理者同步：345页“保护人变成主”缺“僭”；361页“偕主”应为“僭主”；364页“财富奴隶-一起”有多余连字符；369页“知识，推理”应为“知识、推理”；408页“格律一一它”应为“格律——它”，同一原问“自已”应为“自己”。题库使用扫描原句，不为使错误OCR通过定位而反向修改正确原问。标点或字形不明确的地方不作猜测性更改。

上述修正同步后，24题的原句锚点均在全文中唯一出现，并落在各自记录的印刷页；正确选项与原句完全相同，PDF页偏移、三个选项ID、解释及逐项反馈的字数限制也全部满足。该结果验证题目定位和格式，不据此宣称全书已逐字校勘。
