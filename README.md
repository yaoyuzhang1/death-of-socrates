# 理想国 · 苏格拉底的下一问

逐页阅读柏拉图《理想国》全十卷，从20个并列的主题章中自由选章。在95处关键问答比较“哪句话更像一个好问题”，并在正文中完成89处理解检查。每次确认后获得动画、提示音和解释录音；选错可重试。读完原来的前8章开启隐藏章节《苏格拉底之死》，读完全部20章获得全书总结。

**[在线阅读](https://yaoyuzhang1.github.io/death-of-socrates/)** · [玩法](docs/playing.md) · [底本与校订](docs/sources.md)

正文采用郭斌和、张竹明译《理想国》，商务印书馆1986年8月第一版，覆盖全十卷（印刷书页1—426）。按完整讨论划分主题章，人物发言、短应答与原有顺序保留；以文字阅读为核心，配有彩色漫画场景和答题解释录音。

## 选择怎样开始

首页以一句玩法和一幅场景画开始，将20章分成“正义”“城邦”“认识”“政制”“命运”五组，默认只显示当前组的2—5章。每章有独立封面卡，显示章号、标题、一句讨论焦点与当前进度，点击卡片即可翻开。按卷或兴趣主题查找、短阅读路线、人物与玩法、术语及全书统计都按需展开；每张卡的详细记录和篇幅另行折叠。

章首与章末使用相同的封面和明确章号，使进入、阅读与完成一章的边界更清楚。章首导引说明讨论从哪里接续、可以留意什么，详细内容可展开；章末回顾论证进展，并保留尚待讨论的问题。首页分组只改变浏览方式，章节编号仍沿原典次序。

20章从一开始全部开放。新章从章首开始，已开始的章接续各自保存的位置。切换章节不会清除其他章的页码、阅读进度、首次答案、通过状态、重练或书签。每章内部沿原文次序阅读，不设置支线或改写原典的结局。导引和回顾明确标为编辑内容，不能代替原作论证。

## 阅读、提问与反馈

每页容纳几轮相邻对话，通常最多12段、760字，尽量将发问和短回应放在一起；场景转换另分页，长发言在标点附近续页。苏格拉底、其他对话者与叙述采用克制的字体、字号和底色差异。漫画随本页谈话或例子选取，按比例完整展示；图注与查看按钮放在画面下方。点击大图后适配屏幕宽高，手机横屏也可查看整幅画面。首页、章节封面和隐藏关卡采用同样的完整显示原则。宽屏左侧显示此刻人物与场景，窄屏可展开查看。

核心练习从三个问法中选择“哪句话更像一个好问题”。正确项引用译本中的原问，另外两项是相关备选问法。反馈指出各项检查了什么、遗漏了什么；不以“苏格拉底说过”作为优劣理由，也不要求玩家赞同书中的全部主张。题前没有解题提示。选错后听该项解释，再重新作答；选对后听说明，并接着阅读原问与人物回应。

89处理解检查附在相应正文页末，检查刚读过的区别、论证条件、类比或故事内容，不要求预测后文。它们与95道核心练习分别保存首次选择、尝试次数和通过状态。原作的主张、已接受的前提和仍待证明的结论分别说明；寓言和神话也不被当成已经确证的事实。

每轮“重练”最多五问，优先安排首次错选且尚未重练答对的题。题前原文可分页回看，选项重新排序，答对后继续。重练不覆盖首次答案，也不移动主篇阅读位置。长选项的确认区保持可见；焦点在选项内时，1—3选择、Enter确认。动画尊重系统的减少动态效果设置。

主篇包含62幅正文漫画和4幅新增封面，共66幅；隐藏章节另有12幅，总计78幅。20个章节封面各不相同，其中16幅选自既有图，4幅新增图表现阳光中的可见世界、古希腊广场、画家与木床、选择的意象。它们是AI生成的编辑配图，并非原版书内插图；命运章的卷轴意象不宣称复原原典仪式。制作说明见[插画说明](docs/art-direction.md)。

## 两个完成里程碑

第一至四卷的原8个主题章完成后，开启《苏格拉底之死》并提供普通话祝贺。这一入口一直保留，不因增加后六卷而收回。新玩家完成同样的8章也得到这一奖励。

全部20章完成后，另有全书总结与祝贺，展示各章阅读足迹与95次核心练习的首次记录。理解检查记录另行保留，各章小结可查看完成数。首次选错不妨碍完成，只需按规则重试并读完后文。旧8章完成不被自动算作后12章完成。

隐藏章节共12幕，从法庭走到牢房。每幕先提供三个不计对错的谈话角度，确认后听人物回应与说明，再完成一处理解判断。判断错选可重试，正确后继续；已经探索的角度、首次选择和判断记录分别保存。已通关旧记录保留，可主动重新挑战十二幕。

隐藏对白主要依据 Benjamin Jowett 的《申辩篇》《克里同篇》《斐多篇》历史英译独立节译为中文，节述、连接文字和编辑说明另行标识；它不是郭斌和、张竹明的《理想国》译文，也不是庭审实录。出处见[隐藏章节审查](docs/audit-bonus-source.md)与[文本说明](docs/death-sources.md)。选择不改写历史上的生死。

## 声音与保存

声音共738条：95道核心题的285条解释、89处主篇与12处隐藏理解判断的303条解释、148段隐藏对白和说明，以及2条里程碑与全书祝贺。只在确认后播放当前所选项的说明，不提前泄露正确答案；主篇原典仍以文字阅读为核心。隐藏本幕正文可手动朗读，人物使用有区分的标准普通话声线。

配音与提示音可分别开关，解释可重听或停止。翻页、退出、切换后台和关闭配音会停止当前声音。录音作为静态文件随游戏播放，游玩时不向语音服务发送台词。

进度自动保存在当前浏览器，无需账号。阅读设置提供字号、纸色、夜间背景与进度导入导出；新备份同时包含主篇、隐藏与理解判断记录。原8章旧版存档迁移后保留已有位置、首次作答、重练、书签与隐藏资格，新增12章保持未开始。v2至v5旧格式仍按既有规则迁移。

正文“书页”链接打开原版扫描及译者注，可翻页、放大核对，关闭后回到阅读位置，也提供连续全文入口。扫描可能包含后文。电子正文经OCR整理和校正，仍可能有录入误差；字符覆盖检查不能代替逐字学术校勘。

## 本地运行

需要Node.js 22.13或更新的兼容版本及pnpm 11.19.0。

```sh
pnpm install --frozen-lockfile
pnpm run text:build
pnpm test
pnpm run dev
```

生产构建使用 `pnpm run build`，输出至 `dist/`。全文源稿为 `content/source/guo-1986-pages.json`，核心题库为 `content/questions/`，主题分章为 `content/structure.json`，导引为 `content/reading-guide.json`，主篇检查为 `content/learning/checks.json`，隐藏正文与判断为 `content/bonus/death.json` 和 `content/bonus/checks.json`。构建生成书页对照与正文覆盖清单；GitHub Actions负责构建、检查和部署。
