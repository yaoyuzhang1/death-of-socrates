# 理想国 · 苏格拉底的下一问

沿着柏拉图《理想国》第一至四卷阅读，在关键处比较“哪句话更像一个好问题”。作答后揭示苏格拉底的原问，说明这一问怎样承接本段对话，再继续读原文。

**[在线阅读](https://yaoyuzhang1.github.io/death-of-socrates/)** · [玩法](docs/playing.md) · [底本与校订](docs/sources.md)

正文采用郭斌和、张竹明译《理想国》，商务印书馆 1986 年 8 月第一版，收录第一至四卷（书页 1—176），按完整讨论分为八个主题章。保留人物发言、短应答和原有顺序；以文字阅读为核心，无配音、支线或改写结局。

## 怎样阅读

读到提问处，从三个问法中选择并确认，或直接揭示原文。原问对应选项取自译本；另两项只在当前讨论的对象、条件或关系上作小幅变化。题前不附解释或提示，题后说明只涉及本问的论证作用，不引入新例子或延伸评价。

目录与书签用于回看已读内容。首次作答独立保留，复习不会改写首次记录。阅读设置提供字号、纸色与夜间背景、进度导入导出。进度保存在当前浏览器，无需账号。

正文中的“书页”链接打开该页扫描图与连续文本，可核对原句及译者注；该页可能包含尚未读到的后文。扫描图是校核依据。电子正文经本地 OCR 整理和校正，仍可能残留录入误差，不能据字符覆盖检查推定已完成逐字学术校勘。

## 本地运行

需要 Node.js 22.13 或更新的兼容版本及 pnpm 11.19.0。

```sh
pnpm install --frozen-lockfile
pnpm run text:build
pnpm test
pnpm run dev
```

生产构建使用 `pnpm run build`，输出至 `dist/`。正文为 `content/source/guo-1986-pages.json`，题库为 `content/questions/`，分章结构为 `content/structure.json`。构建保留每一个收录的正文字符及其顺序，并生成书页对照与覆盖清单。GitHub Actions 负责构建、检查和部署。
