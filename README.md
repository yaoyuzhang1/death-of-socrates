# 苏格拉底之死

一部包含五章、二十处关键场景的中文哲学叙事游戏。你从庭院中的日常谈话走向审判与狱中的最后讨论，在财富、承诺、伤害、城邦和死亡之间，留下自己的理由。

**[进入游戏](https://yaoyuzhang1.github.io/death-of-socrates/)** · [玩法与内容说明](docs/playing.md) · [文本与图像来源](THIRD_PARTY_NOTICES.md) · [验证记录](docs/validation.md)

游戏没有要求你始终同意苏格拉底。你可以维护承诺、要求充分证据、质疑权威，也可以修订自己早先的立场。人物会接续你已经说过的话；札记保存你的主张、理由、限度和仍未回答的问题。

## 怎样开始

打开游戏后，阅读当前场景，检查材料或完成场景中的操作，再选择自己愿意承担的回应。补充文字是可选的私人札记，不会交给 AI 自动判分。可以回溯并尝试另一条路线；回溯会截去该位置之后的选择。

对话、选项和说明都有完整文字。当前剧情配有 291 句预录普通话，随可见对白播放；关闭声音仍可完成游戏。音频播放不会替你翻页或作出选择。录音与播放检查的范围见[验证记录](docs/validation.md)，未进行覆盖全部音轨的人工听审。

进度自动保存在当前浏览器，也可导出文件，在另一台设备导入。清理站点数据、使用不同浏览器或退出临时浏览模式，可能使本地进度不可用。项目没有账号、云存档或应用分析代码，不向开发者上传札记。网站托管方仍会处理正常网页访问请求。

## 原典与演绎

剧情参考柏拉图《理想国》第一卷、《申辩篇》《克力同篇》《斐多篇》。中文对白是为游戏独立撰写的重述与演绎，不是任何现代中文译本的逐字复制，也不是古代现场的录音或速记。

每个场景显示文本出处与演绎说明。玩家分支、资源分配、扩展案例和跨篇回响属于游戏设计；它们不能作为“柏拉图原话”引用。游戏也不把某一结局当作对苏格拉底全部哲学的最终裁决。详见[来源与解释边界](docs/sources.md)。

## 开发与测试

需要 Node.js 22.13 或更新的兼容版本，以及 pnpm 11.19.0。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run dev
```

生产构建运行 `pnpm run build`，输出到 `dist/`；使用 `pnpm run preview` 检查。GitHub Actions 会先测试、构建，再将 `main` 发布到 GitHub Pages。完整步骤见[发布说明](docs/publishing.md)。
