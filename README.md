# 理想国 · 苏格拉底的下一问

从八个并列的主题章中任选一章，逐页阅读柏拉图《理想国》第一至四卷，在47处关键问答比较“哪句话更像一个好问题”，并在较长阅读段落间完成38处理解检查。确认后获得动画、提示音和解释；选错就再试一次。全部八章完成后，查看阅读总结并开启隐藏章节《苏格拉底之死》。

**[在线阅读](https://yaoyuzhang1.github.io/death-of-socrates/)** · [玩法](docs/playing.md) · [底本与校订](docs/sources.md)

正文采用郭斌和、张竹明译《理想国》，商务印书馆 1986 年 8 月第一版，收录第一至四卷（书页 1—176），按完整讨论分为八个主题章。人物发言、短应答和原有顺序完整保留；以文字阅读为核心，配有彩色漫画场景及答题解释录音。

## 怎样阅读

八章从一开始全部开放。首页章卡或目录中的章标题都能开始新章，已经开始的章节会接续各自保存的位置。切换章节时，其他章节的页码、阅读进度、首次答案、通过状态、重练和书签完整保留。每章内部继续沿原文顺序阅读，章末可自行选择下一章。

每次显示几轮相邻对话：226页正文与47页追问，每页最多12段、760字，尽量将发问和短回应放在一起。场景转换单独分开，长发言在标点附近续页，全文不删减。苏格拉底、其他对话者和叙述采用克制的字体、底色差异；短应答紧凑排布。漫画按本页内容选取，翻页时更换画面，可以点开放大。页码随进度保存。

读到提问处，从三个问法中选择并确认。选错时显示错误反馈并朗读该项解释，点击“再试一次”重新作答；选对后显示成功效果并朗读解释，然后进入原问与回应的正文页。正确项取自译本，另两项是同一讨论中的备选问法。反馈说明各问法检查了什么、还缺少什么，不把“出自苏格拉底”本身当作优劣理由。题前不附解释或提示。

38处理解检查接在正文页末，只检查刚读过的论点、区别或例子的作用，不要求预测后文。各章按阅读量分别安排2、4、2、5、2、13、6、4处，原有连续阅读段的最长间隔由14页缩至5页。新读到的检查答对后继续，已读旧页保留原来的通行状态。检查有独立的首次选择、尝试次数和通过记录，不改写原有47题。逐题原文锚点与分布见[理解检查说明](docs/learning-checks.md)。

宽屏左侧显示当前地点、聚谈背景和正在参与问答的人；窄屏可以展开查看。资料随场景及说话者交替更新，只作人物与场景说明，不提前概括下一问的答案。

“重练”每轮最多五问，优先选择首次错选、旧版直接揭示且尚未重练答对的题。选项重新排序，题前原文也可分页回看；每一问答对后才能进入下一问。本轮结束后可以再练需要重答的题。重练单独记录，不覆盖首次答案，也不移动主线阅读位置。

目录既可自由进入八章，也可回看每章已读内容；书签保留跨章节的阅读标记。首次作答独立保留，复习不会改写首次记录。阅读设置提供字号、纸色与夜间背景、进度导入导出。新备份将阅读进度和主篇、隐藏章节的理解检查一起保存；也支持导入旧版进度文件。进度保存在当前浏览器，无需账号。

正文中的“书页”链接在阅读页内打开扫描图及译者注，可翻页、放大核对，关闭后回到原处；窗口也保留连续全文入口。书页可能包含尚未读到的后文。扫描图是校核依据。电子正文经本地 OCR 整理和校正，仍可能残留录入误差，不能据字符覆盖检查推定已完成逐字学术校勘。

长选项下的确认区随题目保持可见，选中后仍可修改。焦点在选项内时可用1—3选择、Enter确认。回看旧节后，可用“回到最新进度”继续当前章。v2至v5旧版进度自动迁移到v6的分章存档，已读内容与首次记录保留，尚未开始的章节可立即进入。结构和迁移说明见[八章并列阅读](docs/parallel-chapters.md)。

声音包括141条核心追问解释、1条八章完成祝贺、148段隐藏章节对白与说明，以及50处理解判断的150条选项解释。隐藏章节录音覆盖59段固定正文、53段角度回应和36段说明，采用不同的标准普通话人物声线；确认后只播放所选角度的回应与说明，本幕正文可手动朗读。理解检查答对播放正确解释，答错播放该项反馈，候选项未确认时保持安静。录音随游戏保存，游玩时直接播放静态文件；阅读设置可分别关闭配音与提示音，翻页、离开和隐藏页面会停止当前声音。

主篇保留60幅漫画，隐藏章节另有12幅场景漫画。插画为AI生成的场景表现，制作提示词见[插画说明](docs/art-direction.md)。

## 八章之后

八章全部读完后，结算页展示八章完成状态、47次追问的作答情况与首次选中原问的记录，并播放普通话祝贺；关闭配音时保持安静，也可在结算页手动播放或停止。首次选错不会妨碍完成，只需按原有规则重新选对并读完后文。

隐藏章节《苏格拉底之死》分为12幕，从法庭走到牢房。每幕先提供三个不计对错的谈话角度，确认后听人物接话，再完成一处有文本依据的理解判断；判断选错可重试，答对后继续。首次选择、已经探索的角度和判断记录分别保存，可以回来继续听其他回应。人物对白主要从 Benjamin Jowett 的《申辩篇》《克里同篇》《斐多篇》历史英译独立节译为中文；节述、编辑连接与说明另行标识，不属于郭斌和、张竹明译文。149条逐段来源映射另含1段结尾文字，见[隐藏章节审查](docs/audit-bonus-source.md)与[文本说明](docs/death-sources.md)。已通关的旧记录保留，结尾可主动开始十二幕判断挑战。

## 本轮原文与题目审查

47处核心题均核对了原文前后关系：46题保留原有原问，1题把考点后移到同段中带“仅就正义的概念”限定的原问，前面的泛问与应答仍保留在阅读正文中。题目ID、正确选项ID和原有段落ID保留。76个较弱选项、141条逐项反馈及46条解释经过修订，减少明显荒谬的选项，并说明原问在本段检验条件、区分对象或推进论证的具体作用。38处理解检查全部通读，首轮实改30题，再复核修正牧羊人问题双答案、把幸福误写为享乐及缺乏依据的评价。

本轮另依据扫描记录22项录入与段落修正，包括恢复第19页色拉叙马霍斯的漏文、拆开第57页叙述与发言。当前正文为83,876字符、273页。这是针对发现的问题和题目位置的核对，**没有完成176页逐字学术校勘**。审查结论与具体例子见[原文与提问审查汇总](docs/source-question-review.md)。本地生产构建、82项自动化测试、439条相关录音的文本与解码检查，以及全篇通关和最后改动的专项浏览器复测已完成；发布状态见[GitHub Pages工作流](https://github.com/yaoyuzhang1/death-of-socrates/actions/workflows/pages.yml)，验证范围见[验证记录](docs/validation.md)。

## 本地运行

需要 Node.js 22.13 或更新的兼容版本及 pnpm 11.19.0。

```sh
pnpm install --frozen-lockfile
pnpm run text:build
pnpm test
pnpm run dev
```

生产构建使用 `pnpm run build`，输出至 `dist/`。主篇正文为 `content/source/guo-1986-pages.json`，题库为 `content/questions/`，分章结构为 `content/structure.json`，隐藏章节为 `content/bonus/death.json`；新增检查分别位于 `content/learning/checks.json` 和 `content/bonus/checks.json`。主篇现为83,876字符、273页、47次核心追问，理解检查附在原页末；构建保留每一个收录的正文字符及其顺序，并生成书页对照与覆盖清单。GitHub Actions 负责构建、检查和部署。
